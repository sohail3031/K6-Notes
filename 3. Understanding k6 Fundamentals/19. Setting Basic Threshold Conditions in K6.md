# **Thresholds**

**1. What are thresholds?**
	- Thresholds  in k6 are conditions that define acceptable performance criteria in your tests.
	- They are  evaluated at the end of the test run, and if any threshold is not met, the test is considered to have failed.

**2. Why use thresholds?**
	- Provide a clear pass/fail criteria for performance tests.
	- Help automate the validation of performance goals.
	- Enable quick identification of performance regressions or improvements.

**Code:**

```javascript
import http from "k6/http";
import { sleep } from "k6";

export let options = {
	thresholds: {
		"http_req_duration": ["p(95)<500"] // 95% of the requests should be completed under 500ms
	}
}

export default function() {
	http.get("https://test-api.k6.io/public/crocodiles/1/");
	
	sleep(1);
}
```

**Explanation:** 
The above code will check if 95% of the requests have been completed under 500ms of time.

**Code:**

```javascript
import http from "k6/http";
import { sleep, check } from "k6";

export let options = {
	thresholds: {
		"http_req_duration": ["avg<200", "p(90)<300", "max<500"]
	}
}

export default function() {
	let res = http.get("https://test-api.k6.io/public/crocodiles/1/");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

**Explanation:**
Its possible to add multiple values in a single check condition.
