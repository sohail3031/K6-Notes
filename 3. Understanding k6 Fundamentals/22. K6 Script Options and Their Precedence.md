In the following code snippets, we are going to see what are the different options available to pass **configuration options** to k6 script and how to use them. **Note:** the order of the preference is from lower number to higher number in the following options.

1. **Default:** When no configuration options are provided to a k6 script, it will with the default configuration options.

**Code:** 
```javascript
import http from "k6/http";
import { sleep } from "k6";

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```

**Explanation:** As there are no configuration options have been passed to the script, it will run with default options such as 1 virtual user, 1 second, etc.

2. **Config File:** It is possible to define configuration options in a separate file and use them in the k6 script. Instead of importing the file, pass it as an argument when running the script.

**Code:** 
```javascript
// k6 script
import http from "k6/http";
import { sleep } from "k6";

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```

```javascript
// config file
{
	"vus": 5,
	"duration": "10s",
	"thresholds": {
		"http_req_duration": ["avg<200", "p(90)<300", "max<500"]
	}
}
```

```bash
k6 run --config <config_file_name.js> <k6_script_name.js>
```

**Explanation:** The above command will run k6 script with the configuration options provided in the configuration file.

3. **Script Options:** In this option, the configuration options are provided with in the k6 script.

**Code:**
```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
	vus: 5,
	duration: "10s",
	thresholds: {
		http_req_duration: ["avg<200", "p(90)<300", "max<500"]
	}
}

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```

Explanation: The configuration options are provided with the k6 script.

4. **ENV Variables:** In this option, the values are first set as the  environment variables of the system and those values can be used later in scripts.

**Code:**
```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
	vus: __ENV.K6_VUS || 10,
	duration: __ENV.K6_DURATION || "5s",
	thresholds: {
		http_req_duration: ["avg<200", "p(90)<300", "max<500"]
	}
}

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```

```bash
export K6_VUS=5 && export K6_DURATION=10s 
```

```bash
k6 run script.js
```

**Explanation:** Before running the k6 script, first set or update the environment variables and then run the script. The **"__ENV"** is used to access the environment variables and if the variable is missing the value provided will be used.

5. **CLI Flags:** In this option, you can pass configuration options via command line.

**Code:**
```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
	vus: 5
}

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```

```bash
k6 run --vus 5 --duration 10s <k6_script_name.js>
```

**Explanation:** When the script runs, it will use the configuration options passed within the k6 script run command. If the options are missing, it use the provided options in the command and if the options are available, then it will override.
