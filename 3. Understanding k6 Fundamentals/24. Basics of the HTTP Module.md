The following code snippets will show different options and ways to use HTTP requests with different options.

1. **Get Requests:**

**Code:**

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export default function() {
	let res = http.get("https://test.k6.io/");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

**Explanation:** This is a basic example showing how to use **HTTP Get Requests** using **K6** script.

2. **HTTP Params:**

**Code:**

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export default function() {
	const params = {
		cookies: {my_cookies: "value"},
		headers: {"X-MyHeader": "k6test"},
		redirects: 5,
		tags: {k6test: "yes"} // custom field
	};
	
	let res = http.get("https://k6.io/", params);
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

**Explanation:** The parameters are optional and if provided, it will use them in **HTTP** requests.
