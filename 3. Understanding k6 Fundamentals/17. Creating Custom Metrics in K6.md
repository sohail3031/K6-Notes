# **1. Custom Metrics**
- **Counter:** Measures a count of events.
- **Gauge:** Measures a value at a specific point in time.
- **Trend:** Measures statistical trends over time.
- **Rate:** Measures the rate of events over time.

**Code for Counter:**

```javascript
import http from "k6/http";
import { Counter } from "k6/metrics";

let myCounter = new Counter("my_counter");

export default function() {
	http.get("https://test-api.k6.io/public/crocodiles/1/");
	
	myCounter.add(1); // increment the counter
}
```

**Code for Gauge:**

```javascript
import http from "k6/http";
import { Gauge } from "k6/metrics";

let myGauge = new Gauge("my_gauge");

export default function() {
	let res = http.get("https://test-api.k6.io/public/crocodiles/1/");
	
	myGauge.add(res.timings.duration); // capture response time
}
```

**Code for Trend:**

```javascript
import http from "k6/http";
import { Trend } from "k6/metrics";

let myTrend = new Trend("my_trend");

export default function() {
	let res = http.get("https://test-api.k6.io/public/crocodiles/1/");
	
	myTrend.add(res.timings.duration); // records response time trend
}
```

**Code for Rate:**

```javascript
import http from "k6/http";
import { Rate } from "k6/metrics";

let myRate = new Rate("my_rate");

export default function() {
	let res = http.get("https://test-api.k6.io/public/crocodiles/1/");
	
	myRate.add(res.status === 200); // measure rate of successfull events
}
```
