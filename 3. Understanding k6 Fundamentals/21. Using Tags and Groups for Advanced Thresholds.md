In the following code, we are going to see how to use tags and groups.

**General:** Tags and Groups are mechanisms to organize, filter, and aggerate metrics in the results helping for better analyze performance data for different parts of the script.

**Tags:** Tags are used to assign labels or categories to specific elements within k6 script, such as HTTP requests, custom metrics, or checks.

**Groups:** Groups defined using the **group()** function in k6 scripts, are used to structure related logical blocks or user flows.

**Code:** 

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export let options = {
	thresholds: {
		"http_req_duration": ["avg<200", "p(90)<300", "max<500"],
		"http_req_failed": ["rate<0.1"]
	},
	vus: 10,
	duration: "10s"
}

export default function() {
	let res = http.get("https://test-api.k6.io/public/crocodiles/1/");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

**Code:** Using group()

```javascript
import http from "k6/http";
import { group } from "k6";

export let options = {
	thresholds: {
		"group_duration{group:::my_group}": ["avg<400"]
	},
	vus: 10,
	duration:"10s"
}

export default function() {
	group("my_group", function() {
		http.get("https://test-api.k6.io/public/crocodiles/1/");
	});
}
```

**Code:** Using tags

```javascript
import http from "k6/http";

export let options = {
	thresholds: {
		"http_req_duration{staticAsset:true}": ["p(95)<300"]
	},
	vus: 10,
	duration: "10s"
}

export default function() {
	http.get("https://test-api.k6.io/static/some-file.js", {tags: {staticAsset: "true"}});
}
```
