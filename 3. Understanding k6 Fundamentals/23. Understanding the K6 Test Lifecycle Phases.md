K6 test life cycle consists of 4 different phases. They are

1. **Init**
2. **Setup**
3. **VU (Virtual User) Code Execution**
4. **Teardown**

###### **1. Init** 
This is the initial phase in K6 test life cycle. In this phase, the initialization of script is done such as imports, file loads, global variable declaration, and more. This phase is required.

###### **2. Setup** 
This is the second phase in the life cycle and it is optional phase. In this phase, the generation of authentication tokens, loading test data, and more takes place.

###### **3. VU (Virtual User) Code Execution** 
This is the main phase in the life cycle. The default function is executed repeatedly by VUs. This is where API requests (HTTP, WebSocket's, etc.) requests are made and assertions occurs.

###### **4. Teardown** 
This is the final phase in the life cycle. This phase is optional. It is run after all the VUs are finished with the iterations. It is used to cleanup the used resources such as test data.

**Code:**

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

// init
export const options = {
	vus: 1,
	iterations: 1
}

// setup
export function setup() {
	return {assessToken: "secret-token"};
}

// VU
export default function(data) {
	let res = http.get("https://test.k6.io");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}

// teardown
export function teardown(data) {
	return data.accessToken;
}
```

**Note:** The **setup()** and **teardown()** are reserved keyword and you have to use the same for setup and teardown.
