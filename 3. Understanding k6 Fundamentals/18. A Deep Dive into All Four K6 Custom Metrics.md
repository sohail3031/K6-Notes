In the following code, we will see how all the 4 custom metrics work together.

**Code:** 

```javascript
import http from "k6/http";
import { Counter, Gauge, Trend, Rate } from "k6/metrics";
import { sleep } from "k6";

// custom metrics
let successfulRequests = new Counter("successful_requests");
let responseTimeGauge = new Gauge("response_time_gauge");
let responseTimeTrend = new Trend("response_time_trend");
let successRate = new Rate("success_rate");

// test configurations
export let options = {
	stages: [
		{ duration: "10s", target: 5 }, // ramp-up vu's
		{ duration: "20s", target: 5 }, // stay at 5 vu's
		{ duration: "10s", target: 0 } // ramp-down vu's
	],
	thresholds: {
		"successful_requests": ["count>100"], // checks if at least 100 requests are successful
		"response_time_gauge": ["value<500"], // checks if response time is less than 500ms
		"response_time_trend": ["p(95)<500"], // checks if 95% requests response time is less than 500ms
		"success_rate": ["rate>0.9"] // checks the success rate of all the requests should be more than 90%
	} // checks the performance pass/fail criteria of the script 
}

export default function() {
	let res = http.get("https://test-api.k6.io/public/crocodiles/1/");
	let successful_req = res.status === 200; // checks if teh request is successful
	
	// add data to cusotm metrics
	successfulRequests.add(successful_req ? 1 : 0);
	responseTimeGauge.add(res.timings.duration);
	responseTimeTrend.add(res.timings.duration);
	successRate.add(successful_req);
	
	sleep(1);
}
```

**Explanation:** 
The **thresholds** are used to check the performance of the script and based on the conditions mentioned, it will decide whether the test was a success or a failure. **Note:** Thresholds are same as **check** method but they used to check conditions after the execution is completed.
