# **1. Metrics in K6**
1. **Definition:** Metrics in K6 refer to specific data points that offer insights into various aspects of your performance tests.
2. **Purpose:** Metrics help you monitor and evaluate the performance and reliability of your application during test execution.
3. **Quantitative Data:** Metrics capture quantitative information, allowing you to analyze performance trends and identify bottlenecks.
4. **Key Metrics:** Some essential metrics in k6 include response time, throughput, error rate, and virtual user concurrency.
5. **Monitoring and Optimization:** By analyzing metrics, you can optimize your application's performance and enhance its reliability.

# **2. Built-in Metrics**
- **http_reqs:** The number of HTTP requests.
- **http_req_duration:** The time it takes for an HTTP request.
- **http_req_waiting:** The time spent waiting for a response.
- **http_req_connecting:** The time spent establishing a TCP connection.
- **iterations:** The number of iterations executed.
- **vus:** The number of active virtual users.

**Code:**

```javascript
import http from "k6/http";
import { sleep } from "k6";

export default function() {
	http.get("https://test-api.k6.io/public/corcodiles/1/");
	
	sleep(1);
}
```

# **3. Custom Metrics**
- **Counter:** Measures a count of events.
- **Gauge:** Measures a value at a specific point in time.
- **Trend:** Measures statistical trends over time.
- **Rate:** Measures the rate of events over time.
