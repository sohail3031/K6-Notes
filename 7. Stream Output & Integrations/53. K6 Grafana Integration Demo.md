To integrate **Prometheus** into **Grafana Labs**:
- Launch the Grafana Labs
- Go to Data Sources
- Click on **Build a Dashboard** button
- Click on **Import Dashboard** button
- Copy the dashboard ID or download the JSON file from the dashboards
- In **Grafana** dashboards past the ID or past the JSON data
- Click on **Load** button
- Select the data source from **prometheus** dropdown
- Click on **Import** button
- If data is not available, then refresh the dashboard
