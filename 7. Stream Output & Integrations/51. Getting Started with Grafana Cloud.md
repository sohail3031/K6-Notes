**Grafana Cloud:**
	- **Grafana Cloud** is a composable observability platform integrating various monitoring tools, including Prometheus, Loki, and Tempo.
	- It provide a scalable, hosted solution for metrics, logs and traces.

**Key Features:**
	- Managed services for Prometheus, Loki, and Tempo.
	- Visualization with customizable dashboards.
	- Alerting and notifications via Grafana's unified alerting system.
	- Integration with multiple  data sources and monitoring tools.
