**Introduction to Prometheus:**
- **Prometheus:** Monitoring & Alerting Toolkit
- Open-source, originally developed by SoundCloud
- Part of Cloud Native Computing Foundation (CNCF)
- Essential for monitoring modern applications and infrastructure

**Prometheus Architecture:**
- **Prometheus Server:** This is the central part of Prometheus. It scans and stored time series data.
- **Time Series Database:** Its the place where Prometheus uses its own custom database to store data efficiently.
- **Exporters:** There are small programs which extract metrics from third party systems and expose them to Prometheus
- **Metrics Endpoint:** These are the HTTP endpoints that expose metrics data in a format that Prometheus can scrape.
- **Service Discovery:** Prometheus uses it to dynamically discover targets to scrape metrics from ensuring it can adapt to changes in your infrastructure.

**Introducing Grafana for Visualization:**
- **Grafana:** Open-source Analytics and Monitoring
- Powerful Visualization Capabilities
- Integration with Prometheus
- Customizable dashboards and alerts
