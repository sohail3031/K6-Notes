Let's setup QuickPizza application locally using Docker and practice some real world use cases on this application. To setup QuickPizza application locally, follow the below steps:

**Steps:**
1. As we are installing using Docker, you mush have docker installed on your system. If you don't have, then download and install it using the link: [[!https://www.docker.com/products/docker-desktop/]].
2. Clone the code using git or download the code from the GitHub repository [[https://github.com/grafana/quickpizza]].
3. Run the docker application.
4. Open terminal and run the following command:

```bash
docker run --rm -it -p 3333:3333  ghcr.io/grafana/quickpizza-local:latest
```

5. Open the browser and navigate to localhost:3333.
