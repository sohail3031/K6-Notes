In this lecture, the focus is on **submitting an HTML form using K6** and then **verifying whether the submitted values are correctly returned in the response**.

This is useful when you want to test:

- whether a form can be submitted successfully    
- whether the correct field values are sent
- whether the server receives and returns the expected data
- whether the form workflow behaves correctly under load

---

# 🎯 Goal of This Demo

In this example, K6 will:

1. load an HTML form page    
2. submit the form programmatically
3. pass predefined values into the form fields
4. validate the response returned by the server
5. confirm each submitted field has the correct value

---

# 📌 Key Idea

Instead of manually opening a webpage and typing values into a form, K6 can do it automatically using:

```javascript
response.submitForm()
```

This allows you to simulate **real form submission** directly from the script.

---

# ⚙️ K6 Script for Submitting HTML Form

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export default function () {
  let formRes = http.get("https://httpbin.org/forms/post");

  check(formRes, {
    "form page loaded": (r) => r.status === 200,
  });

  let submitRes = formRes.submitForm({
    formSelector: "form",
    fields: {
      comments: "near stall",
      custemail: "asdf@sf.cm",
      custname: "name",
      custtel: "234234",
      delivery: "11:00",
      size: "small",
      topping: "bacon",
    },
  });

  check(submitRes, {
    "form submitted successfully": (r) => r.status === 200,
    "comments is correct":  (r) => r.json().form.comments  === "near stall",
    "custemail is correct": (r) => r.json().form.custemail === "asdf@sf.cm",
    "custname is correct":  (r) => r.json().form.custname  === "name",
    "custtel is correct":   (r) => r.json().form.custtel   === "234234",
    "delivery is correct":  (r) => r.json().form.delivery  === "11:00",
    "size is correct":      (r) => r.json().form.size      === "small",
    "topping is correct":   (r) => r.json().form.topping   === "bacon",
  });

  sleep(3);
}
```

---

# 🧠 What This Script Does

This script performs **two main steps**:

## Step 1: Load the HTML form page

It opens the form page from:

```text
https://httpbin.org/forms/post
```

## Step 2: Submit the form with predefined values

It fills the form fields automatically and submits the form.

Then it verifies whether:

- form submission was successful    
- all submitted values are correctly returned in the response

# 🔍 What `submitForm()` Does

`submitForm()` uses the form returned by `formRes` and submits it with the field values you provide.

## It needs two things:

### 1. `formSelector`

```javascript
formSelector: "form"
```

This tells K6 **which HTML form element to submit**.

Here, `"form"` means:

- select the `<form>` element on the page    

---

### 2. `fields`

```javascript
fields: {
  comments: "near stall",
  custemail: "asdf@sf.cm",
  custname: "name",
  custtel: "234234",
  delivery: "11:00",
  size: "small",
  topping: "bacon",
}
```

This object contains the **field names and values** to be submitted.

Each key must match the **name attribute of the form field** in the HTML form.

For example:

| Field Name  | Value Submitted |
| ----------- | --------------- |
| `comments`  | `near stall`    |
| `custemail` | `asdf@sf.cm`    |
| `custname`  | `name`          |
| `custtel`   | `234234`        |
| `delivery`  | `11:00`         |
| `size`      | `small`         |
| `topping`   | `bacon`         |

# 5️⃣ Validate the Submitted Response

After the form is submitted, the response is stored in:

```javascript
submitRes
```

Now K6 checks whether the server returned the correct values.

```javascript
check(submitRes, {
  "form submitted successfully": (r) => r.status === 200,
  "comments is correct":  (r) => r.json().form.comments  === "near stall",
  "custemail is correct": (r) => r.json().form.custemail === "asdf@sf.cm",
  "custname is correct":  (r) => r.json().form.custname  === "name",
  "custtel is correct":   (r) => r.json().form.custtel   === "234234",
  "delivery is correct":  (r) => r.json().form.delivery  === "11:00",
  "size is correct":      (r) => r.json().form.size      === "small",
  "topping is correct":   (r) => r.json().form.topping   === "bacon",
});
```

---

# 🔍 What These Checks Verify

## 1. Submission status

```javascript
"form submitted successfully": (r) => r.status === 200
```

This confirms the form was submitted successfully.

---

## 2. Individual field validations

Each of these checks verifies that the response contains the exact value submitted.

Example:

```javascript
"custname is correct": (r) => r.json().form.custname === "name"
```

This means:

- parse response JSON    
- go to `form`
- get the `custname` value
- verify it equals `"name"`

Same logic is applied for:

- comments
- email
- customer name
- phone
- delivery time
- size
- topping

K6 can submit the form directly for you.

# ❌ What Happens If a Value Is Wrong?

If you intentionally change a value in the check, for example:

```javascript
"custname is correct": (r) => r.json().form.custname === "wrongname"
```

then that check will fail.

So K6 helps you quickly identify:

- which field was not submitted correctly    
- whether the server returned unexpected data
- whether form handling logic is broken
