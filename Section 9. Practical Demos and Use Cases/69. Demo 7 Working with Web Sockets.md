## What are WebSockets?

WebSockets provide a **full-duplex communication channel** over a single TCP connection, enabling real-time data transfer between clients and servers.

This is particularly useful in applications like:

- Live chat applications
- Online gaming
- Real-time notifications
- Collaborative tools

Unlike HTTP, WebSockets allow continuous two-way communication.

## 6. WebSocket Event Handlers

### On Connection Open

```javascript
        socket.on("open", function () {
            console.log(`VU ${__VU}: Connected`);

            socket.send(
                JSON.stringify({
                    event: "SET_NAME",
                    new_name: `Croc ${__VU}`,
                })
            );

            socket.setInterval(function () {
                socket.send(
                    JSON.stringify({
                        event: "SAY",
                        message: `I'm saying ${randomString(5)}`,
                    })
                );
            }, randomIntBetween(2000, 8000));
        });
```

### Explanation

- Sets username for each VU    
- Sends messages at random intervals (2–8 seconds)

---

### Ping / Pong Events

```javascript
        socket.on("ping", function () {
            console.log("PING!");
        });

        socket.on("pong", function () {
            console.log("PONG!");
        });
```

---

### On Message Received

```javascript
        socket.on("message", function (message) {
            const msg = JSON.parse(message);

            if (msg.event === "CHAT_MSG") {
                console.log(
                    `VU ${__VU} Received: ${msg.user} says ${msg.message}`
                );
            } else if (msg.event === "ERROR") {
                console.error(`VU ${__VU} Error: ${msg.message}`);
            } else {
                console.log(
                    `VU ${__VU} Unhandled message: ${msg.message}`
                );
            }
        });
```

---

### On Close Connection

```javascript
        socket.on("close", function () {
            console.log(`VU ${__VU}: Disconnected`);
        });
```

## 7. Session Timeout Handling

### Leave Chat After Random Duration

```javascript
        socket.setTimeout(function () {
            console.log(
                `VU ${__VU}: ${sessionDuration}ms passed, leaving chat`
            );

            socket.send(JSON.stringify({ event: "LEAVE" }));
        }, sessionDuration);
```

---

### Force Close Connection

```javascript
        socket.setTimeout(function () {
            console.log("Closing socket forcefully after 3s");

            socket.close();
        }, sessionDuration + 3000);
```

## Key Concepts

### 1. WebSocket Connection Lifecycle

- Open    
- Send/Receive messages
- Ping/Pong heartbeat
- Close

---

### 2. Real-Time Messaging Simulation

- Random message intervals simulate real users    
- Multiple VUs act as concurrent chat users

---

### 3. Session Management

- Each user has a random session duration (10–60 seconds)    
- Users leave and disconnect automatically

---

### 4. k6 WebSocket Features

- `ws.connect()` → establish connection    
- `socket.send()` → send messages
- `socket.on()` → event handling
- `socket.setTimeout()` → delayed actions
- `socket.setInterval()` → repeated actions
