Sometimes in performance testing, you don’t just want to verify **status codes** or **response times** — you may also want to validate the **HTML content returned by a page**.

K6 allows you to **parse HTML responses**, query elements like a DOM, and extract values such as:

- page title    
- attributes like `lang`
- text inside elements
- IDs / child nodes / nested values

# 📌 Why HTML Parsing Is Useful in K6

HTML parsing is useful when you want to verify things like:

- whether a page contains the correct **title**

# 1️⃣ Example 1: Parse a Real HTML Page

## Code

```javascript
import { parseHTML } from "k6/html";
import http from "k6/http";

export default function() {
	const res = http.get("https://k6.io");
	const doc = parseHTML(res.body); // equivalent to res.html()
	const pageTitle = doc.find("head title").text();
	const langAttr = doc.find("html").attr("lang");
	
	console.log("pageTitle", pageTitle);
	console.log("langAttr", langAttr);
}
```

---

# 🔍 What This Script Does

This script:

1. sends a **GET request** to `https://k6.io`    
2. reads the HTML response body
3. parses the HTML into a **DOM-like structure**
4. extracts:
    - the **page title**
    - the `lang` attribute of the `<html>` tag
5. prints both values in the console

---

## 1. Import Required Modules


# 2️⃣ Example 2: Parse Static HTML Content

Now instead of parsing a real website response, K6 can also parse a **manually defined HTML string**.

## Code

```javascript
import { parseHTML } from "k6/html";
import { sleep } from "k6";

export default function() {
	const content = `
	<dl>
		<dt id="item-1">Value Item 1</dt>
		<dt id="item-2">Value Item 2</dt>
	</dl>
	`;
	const sel = parseHTML(content).find("dl").children();
	const el1 = sel.get(0);
	const el2 = sel.get(1);
	
	console.log(el1.nodeName());
	console.log(el1.id());
	console.log(el1.textContent());
	
	console.log(el2.nodeName());
	console.log(el2.id());
	console.log(el2.textContent());
	
	sleep(1);
}
```

---

# 🔍 What This Script Does

This script:

1. creates a small HTML block manually    
2. parses it using `parseHTML()`
3. finds the `<dl>` element
4. gets its child elements
5. extracts details from each child:
    - node name
    - id
    - text content

---

# 🧠 Step-by-Step Breakdown

## 1. Create Static HTML

```javascript
const content = `
<dl>
	<dt id="item-1">Value Item 1</dt>
	<dt id="item-2">Value Item 2</dt>
</dl>
`;
```

This creates a small HTML snippet in string format.

It contains:

- one `<dl>`    
- two `<dt>` child elements

---

## 2. Parse the HTML and Get Children

```javascript
const sel = parseHTML(content).find("dl").children();
```

### What happens here:

- parse the HTML string    
- find the `<dl>` element
- get its child elements

So `sel` contains the two `<dt>` elements.

---

## 3. Access Individual Child Elements

```javascript
const el1 = sel.get(0);
const el2 = sel.get(1);
```

This gets:

- first `<dt>` → `el1`    
- second `<dt>` → `el2`

---

## 4. Extract Information from Each Element

### For first child:

```javascript
console.log(el1.nodeName());
console.log(el1.id());
console.log(el1.textContent());
```

### For second child:

```javascript
console.log(el2.nodeName());
console.log(el2.id());
console.log(el2.textContent());
```

---

# 📌 What Each Method Returns

## `nodeName()`

Returns the HTML tag name.

For both elements, it returns:

```text
DT
```

---

## `id()`

Returns the `id` attribute of the element.

For example:

- `item-1`
- `item-2`

---

## `textContent()`

Returns the text inside the tag.

For example:

- `Value Item 1`
- `Value Item 2`

# 🧠 Important K6 HTML Parsing Methods

Here are the main methods used in this lecture:

| Method            | Purpose                                   |
| ----------------- | ----------------------------------------- |
| `parseHTML(html)` | Converts HTML string into DOM-like object |
| `.find(selector)` | Finds element using CSS selector          |
| `.text()`         | Gets text from selected element           |
| `.attr("name")`   | Gets an attribute value                   |
| `.children()`     | Gets child elements                       |
| `.get(index)`     | Gets a specific child by index            |
| `.nodeName()`     | Returns tag name                          |
| `.id()`           | Returns element ID                        |
| `.textContent()`  | Returns full text content                 |

# ⚠️ Important Note

HTML parsing in K6 works well when the HTML content is present in the **HTTP response**.

If a page heavily depends on **JavaScript rendering in the browser**, then the raw HTML response may not contain everything you see in the browser UI.

So HTML parsing is best for:

- static HTML responses    
- server-rendered pages
- direct content validation from response body

---

# 💡 `parseHTML(res.body)` vs `res.html()`

In K6, this:

```javascript
const doc = parseHTML(res.body);
```

is effectively similar to:

```javascript
const doc = res.html();
```

Both allow you to work with the HTML response in a DOM-like way.
