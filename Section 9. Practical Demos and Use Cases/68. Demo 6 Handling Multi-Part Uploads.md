Welcome to this lecture on uploading and testing file content in k6.

In this session, we will explore a practical example demonstrating how to upload multiple files using an HTTP POST request with **multipart/form-data encoding**, and how to verify the response.

We will also learn how to validate uploaded content by inspecting the server response.

---

## What is Multipart Form Data?

Multipart form-data is used when uploading files via HTTP. It allows:

- Uploading binary files (images, PDFs, etc.)
- Sending text fields along with files
- Sending multiple files in a single request

k6 supports multipart uploads using the `FormData` utility.

## Code Explanation

### 1. Import Required Modules

```javascript
import http from "k6/http";
import { check } from "k6";
import { FormData } from "https://jslib.k6.io/formdata/0.0.2/index.js";
```

---

### 2. Read Files in Binary Mode

We use `open()` to read files from the local directory.

```javascript
const img1 = open("image1.png", "b");
const img2 = open("image2.jpg", "b");
const txt = open("text.txt");
```

### Explanation

- `"b"` → opens file in binary mode
- Required for images and non-text files
- Files must exist in the same directory as the script

---

### 3. Create FormData Object

We create a `FormData` instance to construct multipart body.

```javascript
export default function () {
    const fd = new FormData();
```

---

### 4. Append Fields and Files

We can append both text fields and files.

```javascript
    fd.append("someTextFile", "someValue");

    fd.append(
        "aBinaryFile",
        {
            data: new Uint8Array(img1).buffer,
            filename: "logo.png",
            content_type: "image/png",
        }
    );

    fd.append("anotherTextFile", "anotherValue");

    fd.append("images", http.file(img1, "image1.png", "image/png"));
    fd.append("images", http.file(img2, "image2.jpg", "image/jpeg"));

    fd.append("text", http.file(txt, "text.txt", "text/plain"));
```

### Explanation

- `append(key, value)` adds form fields
- Text fields are added directly as strings
- Files are added using:
    - `http.file()`
- Multiple files can be appended under the same key (e.g., `"images"`)

---

## 5. Sending the HTTP POST Request

```javascript
    const res = http.post(
        "https://httpbin.org/post",
        fd.body(),
        {
            headers: {
                "Content-Type":
                    "multipart/form-data; boundary=" + fd.boundary,
            },
        }
    );
```

### Explanation

- `fd.body()` → generates multipart payload
- Boundary is required for multipart requests
- `httpbin.org/post` is used for testing requests

---

## 6. Validate Response Status

```javascript
    check(res, {
        "status is 200": (r) => r.status === 200,
    });
```

---

## 7. Parse and Validate Response Data

```javascript
    const json = res.json();
```

The response contains:

- `form` → text fields
- `files` → uploaded files

---

### Validation Checks

```javascript
    check(json, {
        "has someTextFile": (j) =>
            j.form.someTextFile === "someValue",

        "has anotherTextFile": (j) =>
            j.form.anotherTextFile === "anotherValue",

        "has aBinaryFile": (j) =>
            j.files["aBinaryFile"] !== undefined,

        "has images[0]": (j) =>
            j.files["images"][0] !== undefined,

        "has images[1]": (j) =>
            j.files["images"][1] !== undefined,

        "has text file": (j) =>
            j.files["text"] !== undefined,
    });
}
```

## Key Concepts

### 1. FormData in k6

- Used to construct multipart requests
- Supports text + binary data

### 2. File Upload Handling

- `http.file()` wraps file content
- Multiple files can be sent under same key

### 3. Response Structure

- `form` → text fields
- `files` → uploaded file contents

### 4. Validation Strategy

- Verify HTTP status
- Verify uploaded fields exist in response
- Verify file arrays when multiple files are uploaded
