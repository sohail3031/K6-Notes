**`gracefulRampDown`** is an option exclusive to the [`ramping-vus` executor](https://grafana.com/docs/k6/latest/using-k6/scenarios/executors/ramping-vus/) and applies _between stages_ when the target number of VUs is decreasing. It controls how long VUs whose number is being reduced have to complete their current iteration before they are returned to the pool (terminated) to meet the lower VU target of the next stage. It ensures a smooth transition between different load levels.

**Code:**

```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
	scenarios: {
		ramping_load: {
			executor: "ramping-vus",
			startVUs: 1,
			stages: [
				{ duration:  "10s", target: 10 },
				{ duration: "10s", target: 0 }
			],
			gracefulRampDown: "5s" // allow 5 seconds for iterations to complete during ramp down
		}
	}
};

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```
