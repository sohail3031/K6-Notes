**`gracefulStop`** defines the time k6 should wait for any currently running iterations to finish _after the scenario's main duration has ended_. If an iteration doesn't complete within this period (default 30s), it is forcefully interrupted. This option is available for most executors (like `constant-vus`, `shared-iterations`, etc.) and acts as a final cleanup period for the entire scenario execution.

**Code:**

```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
	scenarios: {
		graceful_stop_scenario: {
			executor: "constant-vus",
			vus: 5,
			duration: "10s",
			gracefulstop: "5s" // allow 5 seconds for iterations to complete before stopping
		}
	}
};

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```
