**Definition:** In K6, scenarios are used to model different, realistic user behavior and load patterns within a single test script. Instead of running one uniform script, you can orchestrate multiple workflows (e.g. user browsing vs users placing orders) with distinct configurations, such as different virtual user (VU) ramp-up or execution strategies.

**Key Concepts:**
1. **Executors:** The core of K6 scenario is its executor, which determines how VUs and iterations are scheduled. Common types include **"constant-vus"**, **"ramping-vus"**, and **"constant-arrival-rate"**.
2. **Parallel or Sequential:** Scenarios can run in parallel by default, or sequentially using the **"startTime"** option to offset their execution.
3. **Realism:** Scenarios help model real-world traffic by allowing you to define the logic (user behavior) and load (traffic volume) separately for different user journeys.

**Code:**

```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
	scenarios: {
		simple_scenario: {
			executor: "constant-vus",
			vus: 10, // number of VUs to run concurrently
			duration: "30s" // duration for script to run
		}
	}
};

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```
