Welcome to this lecture on using thresholds in browser testing with k6.

Thresholds in k6 allow you to define **performance goals** and automatically validate whether your application meets those expectations during test execution.

## Full Script

```javascript
import { browser } from "k6/browser";
import { check } from 'https://jslib.k6.io/k6-utils/1.5.0/index.js';

const BASE_URL = __ENV.BASE_URL || "http://localhost:3333";

export const options = {
  scenarios: {
    ui: {
      executor: "shared-iterations",
      options: {
        browser: {
          type: "chromium",
        },
      },
    },
  },
  thresholds: {
    browser_web_vital_fcp: ["p(95) < 1000"],
    browser_web_vital_lcp: ["p(95) < 2000"],
  },
};

export default async function () {
  let checkData;
  const page = await browser.newPage();

  try {
    await page.goto(BASE_URL);

    checkData = await page.locator("h1").textContent();

    check(checkData, {
      header: checkData == "Looking to break out of your pizza routine?",
    });

    await page.getByRole("button", { name: "Pizza, Please!" }).click();
    await page.waitForTimeout(500);
    await page.screenshot({ path: "screenshot.png" });

    checkData = await page.locator("div#recommendations").textContent();

    check(checkData, {
      recommendation: checkData != "",
    });
  } finally {
    await page.close();
  }
}
```

---

## **What this script demonstrates**

This browser test:

- Launches a Chromium browser
- Navigates to the QuickPizza application
- Performs UI interactions
- Measures Core Web Vitals:
    - **FCP (First Contentful Paint)**
    - **LCP (Largest Contentful Paint)**
- Validates performance using thresholds

---

## **Core Web Vitals Thresholds**

In this script, two key performance metrics are validated:

### 🔹 1. FCP (First Contentful Paint)

```javascript
browser_web_vital_fcp: ["p(95) < 1000"]
```

- Measures time until the first visible content appears
- Ensures **95% of page loads are under 1000ms**

---

### 🔹 2. LCP (Largest Contentful Paint)

```javascript
browser_web_vital_lcp: ["p(95) < 2000"]
```

- Measures time until the largest visible element is rendered
- Ensures **95% of page loads are under 2000ms**

## **What k6 measures automatically**

While the script runs, k6 collects:

### 📊 Browser Performance Metrics

- FCP (First Contentful Paint)
- LCP (Largest Contentful Paint)
- CLS (Cumulative Layout Shift)
- INP (Interaction to Next Paint)

---

## **How threshold evaluation works**

At the end of the test:

- k6 calculates percentile values (like p95)
- Compares them against defined limits
- Marks test as:
    - ✅ PASS if within limits
    - ❌ FAIL if exceeded

---

## **Key concept**

> Thresholds convert performance testing into **automatic quality enforcement**

Instead of just observing metrics, you define:

- What is acceptable
- What is not acceptable
- And let k6 decide pass/fail
