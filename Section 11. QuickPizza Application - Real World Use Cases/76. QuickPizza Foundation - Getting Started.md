## Code Explanation

### Full Script

```javascript id="quickpizza_basic_script"
import http from "k6/http";
import { check, sleep } from "k6";

// Base URL from environment variable or fallback to local QuickPizza
const BASE_URL = __ENV.BASE_URL || "http://localhost:3333";

export const options = {
    vus: 5,
    duration: "5s",
};

export default function () {

    // Request payload (pizza constraints)
    let restrictions = {
        maxCaloriesPerSlice: 500,
        mustBeVegetarian: false,
        excludedIngredients: ["pepperoni"],
        excludedTools: ["knife"],
        maxNumberOfToppings: 6,
        minNumberOfToppings: 2
    };

    // API request
    let res = http.post(
        `${BASE_URL}/api/pizza`,
        JSON.stringify(restrictions),
        {
            headers: {
                "Content-Type": "application/json",
                "Authorization": "token abcdef0123456789",
            },
        }
    );

    // Validate response
    check(res, {
        "status is 200": (r) => r.status === 200,
    });

    // Log response data
    console.log(
        `${res.json().pizza.name} (${res.json().pizza.ingredients.length} ingredients)`
    );

    // Simulate user think time
    sleep(1);
}
```

## Key Concepts

### 1. Environment Variable Usage

```javascript
const BASE_URL = __ENV.BASE_URL || "http://localhost:3333";
```

- Uses `BASE_URL` from environment if available
- Falls back to local QuickPizza instance
- Best practice: always provide a default value

---

### 2. Virtual Users and Duration

```javascript
export const options = {
    vus: 5,
    duration: "5s",
};
```

- 5 virtual users simulate concurrent traffic
- Test runs for 5 seconds
- Useful for quick load validation

---

### 3. Request Payload (Restrictions)

```javascript
let restrictions = {
    maxCaloriesPerSlice: 500,
    mustBeVegetarian: false,
    excludedIngredients: ["pepperoni"],
    excludedTools: ["knife"],
    maxNumberOfToppings: 6,
    minNumberOfToppings: 2
};
```

- Defines constraints for pizza generation
- Simulates realistic user preferences
- Sent as JSON body in POST request

---

### 4. HTTP POST Request

```javascript
http.post(`${BASE_URL}/api/pizza`, JSON.stringify(restrictions), {
    headers: {
        "Content-Type": "application/json",
        "Authorization": "token abcdef0123456789",
    },
});
```

- Sends data to `/api/pizza`
- Includes authentication token
- Uses JSON format

---

### 5. Response Validation

```javascript
check(res, {
    "status is 200": (r) => r.status === 200,
});
```

- Ensures request succeeded
- Validates API behavior

---

### 6. Logging Response Data

```javascript
console.log(
    `${res.json().pizza.name} (${res.json().pizza.ingredients.length} ingredients)`
);
```

- Extracts pizza name
- Counts number of ingredients
- Helps verify response structure

---

### 7. Think Time Simulation

```javascript
sleep(1);
```

- Simulates real user delay
- Improves realism of load test
