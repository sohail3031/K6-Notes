## 🚀 What this script demonstrates

This script focuses on **custom reporting in k6**, specifically:

- 🧾 `handleSummary()` function
- 📄 JSON report generation
- 🖥 formatted CLI output
- 📊 integration-ready test results

## Full Script

```javascript
import http from "k6/http";
import { check, sleep } from "k6";
import { Trend, Counter } from "k6/metrics";
import { textSummary } from "https://jslib.k6.io/k6-summary/0.0.2/index.js";

const BASE_URL = __ENV.BASE_URL || 'http://localhost:3333';

export const options = {
  stages: [
    { duration: '5s', target: 5 },
    { duration: '10s', target: 5 },
    { duration: '5s', target: 0 },
  ],
  thresholds: {
    http_req_failed: ['rate<0.01'],
    http_req_duration: ['p(95)<500', 'p(99)<1000'],
    quickpizza_ingredients: [{ threshold: 'avg<8', abortOnFail: false }],
    checks: ["rate > 0.95"]
  },
};

const pizzas = new Counter('quickpizza_number_of_pizzas');
const ingredients = new Trend('quickpizza_ingredients');

export function setup() {
  let res = http.get(BASE_URL)

  if (res.status !== 200) {
    throw new Error(`Got unexpected status code ${res.status} when trying to setup. Exiting.`)
  }
}

export default function () {
  let restrictions = {
    maxCaloriesPerSlice: 500,
    mustBeVegetarian: false,
    excludedIngredients: ["pepperoni"],
    excludedTools: ["knife"],
    maxNumberOfToppings: 6,
    minNumberOfToppings: 2
  }
  let res = http.post(`${BASE_URL}/api/pizza`, JSON.stringify(restrictions), {
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'token abcdef0123456789',
    },
  });

  check(res, { "status is 200": (res) => res.status === 200 });

  console.log(`${res.json().pizza.name} (${res.json().pizza.ingredients.length} ingredients)`);

  pizzas.add(1);
  ingredients.add(res.json().pizza.ingredients.length);

  sleep(1);
}

export function teardown() {
  // TODO: Send notification to Slack
  console.log("That's all folks!")
}

export function handleSummary(data) {
  return {
    'summary.json': JSON.stringify(data, null, 2),
    stdout: textSummary(data, { indent: " ", enableColors: true }),
  }
}
```

# 🧠 What is `handleSummary()`?

```javascript
export function handleSummary(data) {
  return {
    'summary.json': JSON.stringify(data, null, 2),
    stdout: textSummary(data, { indent: " ", enableColors: true }),
  }
}
```

### ✔ Meaning:

It runs **after the test execution completes** and receives:

👉 `data` = full test result object

---

# 📦 Output 1: JSON Summary File

```javascript
'summary.json': JSON.stringify(data, null, 2)
```

### ✔ What it does:

Creates a structured file:

```
summary.json
```

### ✔ Contains:

- metrics (http_req_duration, failure rate, etc.)
- thresholds results
- scenario stats
- checks results
- execution metadata

### ✔ Why it's useful:

- CI/CD pipelines (GitHub Actions, Jenkins)
- Grafana ingestion
- Post-test analysis tools

---

# 🖥 Output 2: Human-readable Console Summary

```javascript
stdout: textSummary(data, { indent: " ", enableColors: true })
```

### ✔ What it does:

Prints formatted output in terminal:

- colored pass/fail status
- neatly structured metrics
- readable thresholds

### ✔ Example output style:

```bash
✔ checks.......................: 98.7% ✓ 120 ✗ 2
✔ http_req_duration...........: avg=320ms p(95)=450ms
✔ http_req_failed............: 0.5%
```

# 🔁 Execution Flow

When you run:

```bash
k6 run --out cloud ./k6/foundations/10.summary.js
```

### Step-by-step:

1. 🧪 Setup runs (validates API)
2. 🔁 Load test executes (stages)
3. 📊 Metrics collected:
    - Counter → pizzas
    - Trend → ingredients
    - checks + thresholds
4. 🧾 Test finishes
5. 📄 `handleSummary()` runs
6. Outputs generated:
    - `summary.json`
    - CLI formatted report
