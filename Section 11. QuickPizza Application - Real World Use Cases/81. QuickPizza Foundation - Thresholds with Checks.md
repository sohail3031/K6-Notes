# 🧪 06. checks-with-thresholds.js — What’s happening

## Full Script

```javascript
import http from "k6/http";
import { check, sleep } from "k6";
import { Trend, Counter } from "k6/metrics";

const BASE_URL = __ENV.BASE_URL || 'http://localhost:3333';

export const options = {
  stages: [
    { duration: '5s', target: 5 },
    { duration: '10s', target: 5 },
    { duration: '5s', target: 0 },
  ],
  thresholds: {
    http_req_failed: ['rate<0.01'],
    http_req_duration: ['p(95)<500', 'p(99)<1000'],
    quickpizza_ingredients: [{ threshold: 'avg<8', abortOnFail: false }],
    checks: ["rate > 0.95"]
  },
};

const pizzas = new Counter('quickpizza_number_of_pizzas');
const ingredients = new Trend('quickpizza_ingredients');

export function setup() {
  let res = http.get(BASE_URL)

  if (res.status !== 200) {
    throw new Error(`Got unexpected status code ${res.status} when trying to setup. Exiting.`)
  }
}

export default function () {
  let restrictions = {
    maxCaloriesPerSlice: 500,
    mustBeVegetarian: false,
    excludedIngredients: ["pepperoni"],
    excludedTools: ["knife"],
    maxNumberOfToppings: 6,
    minNumberOfToppings: 2
  }
  let res = http.post(`${BASE_URL}/api/pizza`, JSON.stringify(restrictions), {
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'token abcdef0123456789',
    },
  });

  check(res, { "status is 200": (res) => res.status === 200 });

  console.log(`${res.json().pizza.name} (${res.json().pizza.ingredients.length} ingredients)`);

  pizzas.add(1);
  ingredients.add(res.json().pizza.ingredients.length);

  sleep(1);
}
  
export function teardown() {
  // TODO: Send notification to Slack
  console.log("That's all folks!")
}
```

## 1. Load Pattern (Stages)

```js
stages: [
  { duration: '5s', target: 5 },
  { duration: '10s', target: 5 },
  { duration: '5s', target: 0 },
]
```

This means:

- ramp up to 5 VUs
- hold steady load
- ramp down to 0

👉 Purpose: simulate real user traffic lifecycle

---

## 2. Setup Phase (Pre-test validation)

```js
export function setup() {
  let res = http.get(BASE_URL)

  if (res.status !== 200) {
    throw new Error(...)
  }
}
```

### What it does:

- checks if QuickPizza is alive before testing
- aborts test if system is down

👉 This prevents “fake test failures”

```js
http.post(`${BASE_URL}/api/pizza`, ...)
```

👉 Sends request to backend

---

### ✔ Step 3: Check (Business Validation)

```js
check(res, {
  "status is 200": (res) => res.status === 200
});
```

This is a **soft validation**:

- success = true/false per request
- used later in thresholds

```js

```

👉 Debug visibility of responses

# 🚦 5. THE MOST IMPORTANT PART: Thresholds

This is where k6 becomes a **quality gate system**

---

## 🔴 1. Failure Rate Threshold

```js
http_req_failed: ['rate<0.01']
```

👉 Meaning:

- less than 1% requests can fai

✔ ensures system reliability

---

## 🟠 2. Performance Thresholds

```js
http_req_duration: [
  'p(95)<500',
  'p(99)<1000'
]
```

👉 Meaning:

- 95% requests must finish < 500ms
- 99% requests must finish < 1s

✔ ensures response time SLA

---

## 🟡 3. Custom Metric Threshold

```js
quickpizza_ingredients: [
  { threshold: 'avg<8', abortOnFail: false }
]
```

👉 Meaning:

- average ingredients per pizza must be < 8
- test will NOT stop if it fails

✔ ensures data quality constraint

---

## 🟢 4. Checks Threshold (NEW concept)

```js
checks: ["rate > 0.95"]
```

### This is very important.

It means:

> At least 95% of all `check()` validations must pass

---

## 🔥 What this really measures

Your check is:

```js
status === 200
```

So this threshold means:

✔ at least 95% of API responses must return 200
