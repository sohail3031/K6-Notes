## What is QuickPizza?

**QuickPizza** is a demo application that simulates a pizza ordering system.

It provides a simple RESTful API for:
- Creating pizza orders
- Managing orders
- Simulating user interactions

This application is widely used in k6 tutorials to demonstrate:
- API performance testing
- User behavior simulation
- Response validation

---

## Why Use QuickPizza?

It helps you practice real-world scenarios such as:
- Load testing REST APIs
- Validating response correctness
- Simulating real user traffic patterns

---

## Running QuickPizza Locally with Docker

QuickPizza can be run locally using Docker, which ensures a consistent environment without manual setup.

---

## Prerequisites

Before starting, ensure you have:

- Docker installed on your system  
  Download: https://www.docker.com/products/docker-desktop/
- Git installed (optional for cloning repo)

---

## Step 1: Clone Repository (Optional)

You can clone the QuickPizza repository:

```bash id="repo_clone"
git clone https://github.com/grafana/quickpizza
```

Or download it directly from:  
[https://github.com/grafana/quickpizza](https://github.com/grafana/quickpizza)

---

## Step 2: Start Docker

Ensure Docker Desktop is running before executing commands.

---

## Step 3: Run QuickPizza Container

```bash
docker run --rm -it -p 3333:3333 ghcr.io/grafana/quickpizza-local:latest
```

---

## Explanation of the Command

### `docker run`

Creates and starts a new container from an image.

---

### `--rm`

Automatically removes the container after it stops  
→ Useful for temporary test environments

---

### `-it`

Combination of:

- `-i` → Keeps input open
- `-t` → Allocates a terminal interface

→ Allows interactive execution

---

### `-p 3333:3333`

Maps ports:

- Local machine: `localhost:3333`
- Container: `3333`

This allows access to the app in your browser.

---

### Image Used

```text
ghcr.io/grafana/quickpizza-local:latest
```

- Official QuickPizza Docker image
- Pulled automatically if not available locally

---

## Step 4: Verify Setup

After running the container:

Open in browser:

```text
http://localhost:3333
```

You should see the QuickPizza application UI running.
