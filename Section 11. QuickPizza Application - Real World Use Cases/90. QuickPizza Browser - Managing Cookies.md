Hi.  
Welcome to this lecture on handling cookies using the k6 experimental browser module.

Cookies are essential in web applications for:

- Session management
- User tracking
- Storing preferences

In this session, we learn how to manage cookies within browser automation scripts.

## Full Script

```javascript
import { browser } from "k6/browser";
import { check } from 'https://jslib.k6.io/k6-utils/1.5.0/index.js';

const BASE_URL = __ENV.BASE_URL || "http://localhost:3333";

export const options = {
  scenarios: {
    ui: {
      executor: "shared-iterations",
      options: {
        browser: {
          type: "chromium",
        },
      },
    },
  },
};

export default async function () {
  const pizzaContext = await browser.newContext();

  await pizzaContext.addCookies([
    {
      name: "FooBar",
      value: 123456,
      domain: BASE_URL,
      path: '/',
    },
  ]);

  const pizzaPage = await pizzaContext.newPage();
  const cookies = await pizzaContext.cookies();
  
  await pizzaPage.goto(BASE_URL);

  check(cookies, {
    "cookie length of QuickPizza page": cookies => cookies.length === 1,
    "cookie name": cookies => cookies[0].name === "FooBar",
    "cookie value": cookies => cookies[0].value === "123456"
  });

  await pizzaPage.close();
  await pizzaContext.close();

  const anotherContext = await browser.newContext();
  const anotherPage = await anotherContext.newPage();
  const anotherCookies = await anotherContext.cookies();

  await anotherPage.goto('https://example.org/');  

  check(anotherCookies, {
    "cookie length of example test page": anotherCookies => anotherCookies.length === 0,
  });

  await anotherPage.close();
}
```

---

## **What this script demonstrates**

This script shows how cookies behave across different **browser contexts** in k6:

- Adding cookies to a context
- Reading cookies from a page
- Validating cookie values
- Ensuring isolation between contexts

---

## **Step-by-step explanation**

### **1. Create a browser context**

```javascript
const pizzaContext = await browser.newContext();
```

A **browser context** is an isolated session (like a separate browser profile).

---

### **2. Add cookies to the context**

```javascript
await pizzaContext.addCookies([
  {
    name: "FooBar",
    value: "123456",
    domain: BASE_URL,
    path: "/",
  },
]);
```

This injects a cookie into the context before any page loads.

---

### **3. Create a page inside the context**

```javascript
const pizzaPage = await pizzaContext.newPage();
```

All pages inside this context share the same cookies.

---

### **4. Retrieve cookies**

```javascript
const cookies = await pizzaContext.cookies();
```

This fetches all cookies stored in the current context.

---

### **5. Navigate to the application**

```javascript
await pizzaPage.goto(BASE_URL);
```

---

### **6. Validate cookies**

The script checks:

- Cookie count is 1
- Cookie name is `"FooBar"`
- Cookie value is `"123456"`

```javascript
check(cookies, {
  "cookie length": (cookies) => cookies.length === 1,
  "cookie name": (cookies) => cookies[0].name === "FooBar",
  "cookie value": (cookies) => cookies[0].value === "123456",
});
```

---

### **7. Close first context**

```javascript
await pizzaContext.close();
```

This ensures cleanup and isolation.

---

## **Second browser context (isolation test)**

### **8. Create a new context**

```javascript
const anotherContext = await browser.newContext();
```

This context does **not inherit cookies** from the previous one.

---

### **9. Open a new page and check cookies**

```javascript
const anotherCookies = await anotherContext.cookies();
```

Then navigate to another site:

```javascript
await anotherPage.goto("https://example.org/");
```

---

### **10. Validate no cookies exist**

```javascript
check(anotherCookies, {
  "cookie length is 0": (cookies) => cookies.length === 0,
});
```

This confirms:

- Cookies are **context-isolated**
- No leakage between sessions

---

## **Key Concepts Learned**

### 🔹 Browser Context

- Isolated session
- Separate cookies, cache, storage

### 🔹 Cookies in k6 browser

- Can be added before page load
- Can be read per context
- Are not shared across contexts

### 🔹 Isolation behavior

Each `browser.newContext()` creates a clean environment.

---

## **Main takeaway**

This script demonstrates that:

> Cookies are **scoped to browser contexts**, making k6 browser testing reliable for simulating multiple independent users.
