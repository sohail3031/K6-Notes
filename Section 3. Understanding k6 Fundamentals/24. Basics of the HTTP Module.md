### **Overview**

The **`k6/http`** module is one of the most important built-in modules in K6 because it is used to send **HTTP requests** to your application during performance testing. With this module, you can simulate how users interact with APIs or websites by sending requests such as:

- **GET** → retrieve data    
- **POST** → send data / create resources
- **PUT** → update resources
- **DELETE** → remove resources

It is the core module used in most API and web performance tests.

---

# **1. Basic GET Request in K6**

## **Code**

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export default function() {
	let res = http.get("https://test.k6.io/");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

---

## **Explanation**

This script sends a simple **HTTP GET request** to `https://test.k6.io/`.

### **Step-by-step**

### **1) Import required modules**

```javascript
import http from "k6/http";
import { check, sleep } from "k6";
```

- **`http`** → used to make HTTP requests.
- **`check`** → used to validate the response.
- **`sleep`** → pauses execution to simulate real user wait time.

---

### **2) `export default function()`**

```javascript
export default function() {
```

This is the **main VU (Virtual User) function**.  
Every virtual user runs the code inside this function repeatedly based on the configured iterations/duration.

---

### **3) Send GET request**

```javascript
let res = http.get("https://test.k6.io/");
```

- `http.get()` sends an HTTP **GET** request to the given URL.
- The server response is stored in the variable **`res`**.
- `res` contains useful information such as:
    - `res.status` → HTTP status code
    - `res.body` → response body
    - `res.headers` → response headers
    - `res.timings` → request timing details

---

### **4) Validate response using `check()`**

```javascript
check(res, {
	"status is 200": (r) => r.status === 200
});
```

This verifies whether the request was successful.

- **`res`** is the response object being checked.
- `"status is 200"` is the name of the check.
- `(r) => r.status === 200` checks whether the HTTP status code is **200**.

If true → check passes  
If false → check fails

---

### **5) Pause execution**

```javascript
sleep(1);
```

This pauses the virtual user for **1 second** before the next iteration.  
It simulates **real user think time** instead of sending requests continuously without delay.

---

## **What this script does overall**

1. Sends a GET request to the website
2. Verifies that the response status is **200**
3. Waits for **1 second**

# **2. HTTP Params in K6**

K6 allows you to send **additional request configuration** using a **params object**.

These parameters can include:

- **cookies**
- **headers**
- **redirect limits**
- **tags**
- authentication details
- compression options
- timeout settings, etc.

---

## **Code**

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export default function() {
	const params = {
		cookies: {my_cookies: "value"},
		headers: {"X-MyHeader": "k6test"},
		redirects: 5,
		tags: {k6test: "yes"} // custom field
	};
	
	let res = http.get("https://k6.io/", params);
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

---

## **Explanation**

This example is similar to the first one, but now the request includes **extra parameters**.

---

## **Step-by-step**

### **1) Create a params object**

```javascript
const params = {
	cookies: {my_cookies: "value"},
	headers: {"X-MyHeader": "k6test"},
	redirects: 5,
	tags: {k6test: "yes"}
};
```

This object defines additional settings for the HTTP request.

---

### **2) Cookies**

```javascript
cookies: {my_cookies: "value"}
```

This sends a cookie with the request.

- Cookie name → `my_cookies`
- Cookie value → `value`

This is useful when:

- session tracking is required
- authentication depends on cookies
- application behavior changes based on cookies

---

### **3) Headers**

```javascript
headers: {"X-MyHeader": "k6test"}
```

This sends a custom HTTP header with the request.

- Header name → `X-MyHeader`
- Header value → `k6test`

Headers are commonly used for:

- authentication tokens
- content type
- API keys
- custom metadata

Example:

```javascript
headers: {
	"Authorization": "Bearer token_here",
	"Content-Type": "application/json"
}
```

---

### **4) Redirects**

```javascript
redirects: 5
```

This tells K6 to follow up to **5 redirects** for this request.

For example, if:

- the URL redirects from HTTP → HTTPS
- or redirects to a login page

K6 will follow those redirects up to the specified number.

---

### **5) Tags**

```javascript
tags: {k6test: "yes"}
```

Tags are metadata attached to requests. They help with:

- filtering metrics
- grouping requests in reports
- applying thresholds to specific request categories

For example, later you can use tags in thresholds like:

```javascript
"http_req_duration{k6test:yes}": ["p(95)<500"]
```

This means:

- apply the threshold only to requests tagged with `k6test=yes`

---

### **6) Pass params to the GET request**

```javascript
let res = http.get("https://k6.io/", params);
```

Here the GET request is made along with the params object.

So this request will:

- send the cookie
- include the custom header
- allow up to 5 redirects
- tag the request for reporting/threshold usage

---

### **7) Validate the response**

```javascript
check(res, {
	"status is 200": (r) => r.status === 200
});
```

Again, this confirms that the response status is **200**.

---

### **8) Pause for 1 second**

```javascript
sleep(1);
```

Adds think time between iterations.

---

# **Important Note About HTTP Params**

The **params object is optional**.  
If you do not need cookies, headers, tags, or redirect configuration, you can simply write:

```javascript
http.get("https://test.k6.io/");
```

But if you need to customize the request, you can pass a second argument:

```javascript
http.get(url, params);
```

# **Summary**

## **HTTP module**

The **`k6/http`** module is used to send HTTP requests in K6 scripts.

## **Basic GET request**

```javascript
let res = http.get("https://test.k6.io/");
```

- Sends a GET request
- Stores the response in `res`

## **Using `check()`**

```javascript
check(res, {
	"status is 200": (r) => r.status === 200
});
```

- Validates the response
- Marks the check as pass/fail

## **Using params**

A params object can be passed to customize the request:

- **cookies** → send cookies
- **headers** → send custom headers
- **redirects** → control redirect handling
- **tags** → label requests for filtering/reporting

---

# **Key takeaway**

The **HTTP module** is the foundation of most K6 performance tests because it lets you simulate real user/API traffic.  
The two most important patterns you should remember are:

### **Simple request**

```javascript
let res = http.get("https://test.k6.io/");
```

### **Request with params**

```javascript
let res = http.get("https://test.k6.io/", params);
```
