## 1. Introduction

Cookies are small pieces of data stored on the **client side** and sent to the server with HTTP requests.  
They are commonly used for:

- **session management**    
- **user tracking**
- **storing user preferences**
- **authentication flows**

In k6, cookies can be used to simulate realistic user behavior in performance tests, especially for applications that rely on sessions and personalized responses.

In this lecture, we will look at the basics of handling cookies in k6, including:

- setting cookies
- sending cookies in requests
- reading cookies from responses
- validating cookie values

> **Note:** This lecture covers the basics of cookies. Advanced cookie handling such as **cookie jars**, persistent cookies, and cookie attributes can be explored separately in a dedicated cookies section.

# 3. Sending Cookies in an HTTP Request

One simple way to work with cookies is to send them directly in the request headers.

## Example: Sending a Cookie in the Request Header

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export default function () {
    const res = http.get("https://quickpizza.grafana.com/api/cookies", {
        headers: {
            Cookie: "my_cookie=hello world"
        }
    });

    const body = res.json();

    check(res, {
        "status is 200": (r) => r.status === 200,
        "has cookie 'my_cookie'": () => body.cookies.my_cookie !== undefined,
        "cookie has correct value": () => body.cookies.my_cookie === "hello world"
    });

    sleep(1);
}
```

---

## Explanation

In this script:

- A **GET request** is sent to the endpoint.    
- The request includes a `Cookie` header:

```javascript
Cookie: "my_cookie=hello world"
```

- The server reads that cookie and returns it in the response.
- The response is converted to JSON using:

```javascript
const body = res.json();
```    

### Checks performed:

- the response status is `200`
- the cookie `my_cookie` exists in the response
- the cookie value is exactly `"hello world"`

# 4. Using `cookieJar()` in k6

k6 also provides a **cookie jar** for managing cookies more realistically.

A cookie jar allows you to:

- store cookies for a domain    
- automatically send cookies with future requests
- simulate browser-like cookie behavior

---

# 5. Example: Setting and Overriding Cookies with `cookieJar()`

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export default function () {
	const jar = http.cookieJar();

	jar.set("https://quickpizza.grafana.com/api/cookies", "my_cookie", "hello world");

	const cookies = {
		my_cookie: {
			value: "hello world 2",
			replace: true
		}
	};

	const res = http.get("https://quickpizza.grafana.com/api/cookies", { cookies });

	check(res.json(), {
		"cookie has correct value": (r) => r.cookies.my_cookie === "hello world 2"
	});

	sleep(1);
}
```

---

# 6. Explanation of the `cookieJar()` Example

## Step 1: Create a Cookie Jar

```javascript
const jar = http.cookieJar();
```

This creates a cookie jar for the current virtual user.

---

## Step 2: Set a Cookie in the Jar

```javascript
jar.set("https://quickpizza.grafana.com/api/cookies", "my_cookie", "hello world");
```

This stores a cookie named `my_cookie` with value `"hello world"` for the specified URL.

---

## Step 3: Define Request-Level Cookies

```javascript
const cookies = {
	my_cookie: {
		value: "hello world 2",
		replace: true
	}
};
```

This defines a cookie to be sent with the request.

### Meaning of `replace: true`

If a cookie with the same name already exists, it will be replaced by the new value.

So even though the cookie jar already contains:

```javascript
my_cookie = "hello world"
```

the request will use:

```javascript
my_cookie = "hello world 2"
```

---

## Step 4: Send the Request with Cookies

```javascript
const res = http.get("https://quickpizza.grafana.com/api/cookies", { cookies });
```

This sends the request with the overridden cookie value.

---

## Step 5: Validate the Cookie Value

```javascript
check(res.json(), {
	"cookie has correct value": (r) => r.cookies.my_cookie === "hello world 2"
});
```

This verifies that the server received the updated cookie value.

# 7. Important Concepts

## A. Sending Cookies Manually

You can send cookies using the `Cookie` header directly:

```javascript
headers: {
    Cookie: "my_cookie=hello world"
}
```

This is useful for simple tests.

---

## B. Cookie Jar

Use `http.cookieJar()` when you want more realistic cookie handling.

### Benefits:

- stores cookies per virtual user    
- helps simulate session-based applications
- useful for login and multi-step flows

---

## C. Overriding Cookie Values

If you define cookies in the request and use:

```javascript
replace: true
```

the new cookie value replaces the existing one with the same name.
