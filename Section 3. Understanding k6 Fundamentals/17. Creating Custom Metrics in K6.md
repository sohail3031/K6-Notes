### Overview

In addition to K6’s built-in metrics, you can define **custom metrics** to measure application-specific behavior during performance testing. This is useful when the default metrics are not enough to capture the exact information you want.

K6 supports **4 types of custom metrics**:

1. **Counter** – counts how many times something happens    
2. **Gauge** – stores the latest value of something at a point in time
3. **Trend** – tracks statistical values over time (avg, min, max, percentiles, etc.)
4. **Rate** – measures how often something is true/false as a percentage or ratio

---

# 1) Counter Metric

### What is a Counter?

A **Counter** is used to count the number of occurrences of an event.

### Example Use Cases

- Number of successful logins    
- Number of failed API calls
- Number of search requests processed
- Number of orders placed

### Example Code

```javascript
import http from "k6/http";
import { Counter } from "k6/metrics";

const myCounter = new Counter("my_counter");

export default function () {
  http.get("https://test-api.k6.io/public/crocodiles/1/");

  myCounter.add(1); // increments the counter by 1
}
```

### Explanation

- `new Counter("my_counter")` creates a custom counter metric named **my_counter**.
- `myCounter.add(1)` increases the counter value by **1** every time the script runs.
- If the script runs multiple iterations, the counter keeps increasing.

### When to Use a Counter

Use a **Counter** when you want to track **how many times** an event occurs.

---

# 2) Gauge Metric

### What is a Gauge?

A **Gauge** measures a value at a specific point in time.

It is useful when you want to capture the **current value** of something rather than count it.

### Example Use Cases

- Current response time    
- Current memory usage
- Current CPU usage
- Current queue size

### Example Code

```javascript
import http from "k6/http";
import { Gauge } from "k6/metrics";

const myGauge = new Gauge("my_gauge");

export default function () {
  const res = http.get("https://test-api.k6.io/public/crocodiles/1/");

  myGauge.add(res.timings.duration); // stores the response duration
}
```

### Explanation

- `new Gauge("my_gauge")` creates a custom gauge metric named **my_gauge**.
- `res.timings.duration` gives the response time of the HTTP request.
- `myGauge.add(res.timings.duration)` records that value into the gauge.

### When to Use a Gauge

Use a **Gauge** when you want to track the **value of something at a particular moment**.

---

# 3) Trend Metric

### What is a Trend?

A **Trend** metric is used to record values over time and generate statistics such as:

- Average    
- Minimum
- Maximum
- Median
- 90th percentile
- 95th percentile

### Example Use Cases

- API response times
- Database query times
- Login completion time
- Checkout processing time

### Example Code

```javascript
import http from "k6/http";
import { Trend } from "k6/metrics";

const myTrend = new Trend("my_trend");

export default function () {
  const res = http.get("https://test-api.k6.io/public/crocodiles/1/");

  myTrend.add(res.timings.duration); // records response time for trend analysis
}
```

### Explanation

- `new Trend("my_trend")` creates a trend metric named **my_trend**.
- `myTrend.add(res.timings.duration)` records the response time.
- K6 then calculates statistics such as avg, min, max, median, p(90), and p(95).

### When to Use a Trend

Use a **Trend** when you want to analyze **performance over time** and study statistical patterns.

---

# 4) Rate Metric

### What is a Rate?

A **Rate** measures how frequently something happens successfully or unsuccessfully.

It is commonly used to calculate:

- Success rate    
- Failure rate
- Error rate

### Example Use Cases

- Percentage of successful requests
- Percentage of failed logins
- Percentage of responses meeting SLA conditions
- Percentage of API calls returning 200

### Example Code

```javascript
import http from "k6/http";
import { Rate } from "k6/metrics";

const myRate = new Rate("my_rate");

export default function () {
  const res = http.get("https://test-api.k6.io/public/crocodiles/1/");

  myRate.add(res.status === 200); // true if request was successful
}
```

### Explanation

- `new Rate("my_rate")` creates a rate metric named **my_rate**.
- `res.status === 200` evaluates to either `true` or `false`.
- If it is `true`, K6 counts it as a successful event for the rate metric.
- If multiple requests are made, K6 calculates the ratio of successful events.

### When to Use a Rate

Use a **Rate** when you want to measure the **percentage/frequency of successful or failed events**.

---

# Summary of Custom Metrics

| Metric Type | Purpose                             | Example                                     |
| ----------- | ----------------------------------- | ------------------------------------------- |
| **Counter** | Counts events                       | Number of requests, number of failed logins |
| **Gauge**   | Stores a value at a point in time   | Current response time, memory usage         |
| **Trend**   | Tracks statistical trends over time | Response time trend, transaction duration   |
| **Rate**    | Measures frequency/ratio of events  | Success rate, failure rate                  |

---

# Key Takeaways

- **Counter** → use when you want to **count** events.    
- **Gauge** → use when you want to store the **current value** of a metric.
- **Trend** → use when you want **statistics over time**.
- **Rate** → use when you want to measure **success/failure percentages**.
