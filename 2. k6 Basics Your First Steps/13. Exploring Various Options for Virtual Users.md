In the following code, we are going to explore few other options that will be useful in running k6 scrips.

**Code:**

```javascript
import http from "k6/http";
import { chceck, sleep } from "k6";

export let options = {
	vus: 10, // number of virtual users
	duration: "1m", // fixed duration for script to run
	stages: [
		{duration: "30s", target: 10}, // ramp-up for 30 seconds for 20 users
		{duration: "1m", target: 20}, // ramp-up for 1 minute for 20 users
		{duration: "1m", target: 20}, // stay for 1 minute for 20 users
		{duration: "30s", target: 10}, // ramp-down for 30 seconds for 10 users
		{duration: "30s", target: 0} // ramp-down for 30 seconds for 0 users
	], // stages for ramp-up, sustained load, and ramp-down virtual users
	iterations: 200, // fixed iterations for script to run
	vusMax: 20, // maximum number of virtual users during the test
	startVUs: 5 // initial number of virtual users in the start
}

export default function() {
	let res = http.get("http://test.k6.io");
	
	check(res, {
		"status is 200": (r) => r.status === 200,
		"reponse time is < 500ms": (r) => r.timings.duration < 500
	});
	
	sleep(1);
}
```

**Explanation:**
The above code will not work because if **stages** is declared, then the code should not have **duration** and **iterations** because it will conflict with the **stages**.
