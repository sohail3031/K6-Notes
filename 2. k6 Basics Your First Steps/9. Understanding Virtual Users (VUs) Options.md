# **Virtual Users:**
1. **What are VUs?**
	- Virtual Users (VUs) are essential for simulating real-world user behavior during load testing.
	- They allow you to mimic real user behavior and generate realistic load on system.
2. **Why use VUs?**
	- In performance testing, simulating multiple users interacting with your application simultaneously is crucial.
	- Helps identify potential bottlenecks and ensures your application can handle expected traffic loads.

# **Virtual Users Options:**
1. **vus**:
	- Sets the number of virtual users to run concurrently.
	- Determines how many instances of your test script will execute simultaneously.
2. **duration**:  
	- Specifies the total duration for which the test should run.
	- Helps determine the time window during which the load test will be conducted.
3. **stages**:
	- Allows you to define different stages with varying VU counts and durations.
	- Useful for simulating ramp-up and ramp-down periods in your test scenarios.
4. **iterations**:
	- Sets the total number of script iterations to be executed.
	- Determines how many time the script will repeat during the test.
5. **vusMax**:
	- Specifies maximum number of VUs during a test when using stages.
	- Useful for controlling the upper limit of concurrent VUs.
6. **startVUs**:
	- Defines the initial number of VUs when using stages.
	- Determines the starting point for VU concurrency during ramp-up.

**Code:**

```javascript
// fixed number of VUs for fixed duration
export let options = {
	vus: 10, // number of VUs
	duration: "1m" // duration to run the script
}

// stages for ramp-up and ramp-down
export let options = {
	stages: [
		{duration: "30s", target: 20}, // ramp-up to 20 VUs
		{duration: "1m", target: 20}, // stay at 20 VUs
		{duration: "30s", target: 0} // ramp-down to 0 VUs
	]
}

// fixed number of iterations
export let options = {
	iterations: 100, // total number of iterations 
	vus: 10 // number of VUs
}
```
