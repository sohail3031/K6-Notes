In the following code we are going to see how to run a **K6** script for fixed duration.

**Code:**

```javascript
import http from "k6/http";
import { sleep, check } from "k6";

export let options = {
	vus: 10, // number of virtual users
	duration: "1m" // duration to run the script
}

export default function() {
	let res = http.get("https://test.k6.io");
	
	check(res, {
		"status is 200": (r) => r.status === 200 // checks if the status of the request is 200
	}); // checks the conditions
	
	sleep(1);
}
```

**Explanation:**
1. The code uses **10 Virtual Users** and it will run for **1 minute**.
2. The duration can be in minutes and seconds example "30s" **s** represents seconds or "2m" **m** represents minutes.
3. The **check()** is used to check the conditions specified for each user iteration. It is used to verify assertions for each user iteration.
