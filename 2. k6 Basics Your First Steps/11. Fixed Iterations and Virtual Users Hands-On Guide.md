In following code, we are going to see how to run **K6** script for specific iterations.

**Code:**

```javascript
import http from "k6/http";
import { sleep, check } form "k6";

export let options = {
	vus: 10,
	iterations: 100 // run script for specific iterations
}

export default function() {
	let res = http.get("https://test.k6.io");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

**Explanation:** The code will run for 100 iterations and will stop the execution.
