The following code shows how the virtual users are added and removed in the form of stages.

**Code:**

```javascript
import http from "k6/http";
import { sleep, check } form "k6";

export let options = {
	stages: [
		{duration: "30s", target: 20}, // ramp-up the vus to 20 for 30 seconds
		{duration: "1m", target: 20}, // stay vus 20 for 1 minute
		{duration: "30s", target: 0} // ramp-down the vus to 0 for 30 seconds
	]
}

export default function() {
	let res = http.get("https://test.k6.io");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
	
	sleep(1);
}
```

**Explanation:**
1. The virtual users are added slowly for the initial 30 seconds. 
2. The number of virtual users remains the same in the second stage for 1 minute.
3. The virtual users will start decreasing in the the last seconds of the execution.
