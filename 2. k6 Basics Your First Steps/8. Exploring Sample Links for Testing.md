# **QuickPizza Repository Features**
1. **Basic HTTP Requests:**
	- Learn how to send basic GET and POST requests.
	- Understand response validation using checks.
2. **Virtual Users (VUs):**
	- Simulate multiple users interacting with the application simultaneously.
	- Configure scenarios to test different load patterns.
3. **Parameterization:**
	- Use environment variables to parameterize your tests.
	- Customize test data to simulate real-world scenarios.
4. **Handling HTTP Requests and Response:**
	- Manage different types of HTTP requests and responses.
	- Handle authentication, cookies, and headers.
