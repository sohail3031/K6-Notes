K6 also allows to authenticate the users. There are built-in libraries available for authentication and you can either write code from scratch in your local machine or you can use the basic template provided by Grafana Cloud. To use the template in Grafana Cloud, follow the below steps:

- Create a test by navigating to **Testing & Synthetics** -> **Performance** -> **Projects** -> **Create a New Project/Use an Existing Project** -> **Select Script Building** -> **Script Examples** -> **Authentication/Authorization** -> **Basic Authentication**.
- ![[63.png]]
- Edit or use the same template for testing.
- Click on **Create And Run** button.

**Code:**

```javascript
import encoding from 'k6/encoding'
import http from 'k6/http'
import { check } from 'k6'

const username = 'user'
const password = 'passwd'
export const options = {}

export default function () {
  const credentials = `${username}:${password}`
  
  // Passing username and password as part of the URL will
  // allow us to authenticate using HTTP Basic Auth.
  const url = `https://${credentials}@quickpizza.grafana.com/api/basic-auth/${username}/${password}`
  let res = http.get(url)
  
  // Verify response
  check(res, {
    'status is 200': (r) => r.status === 200,
    'is authenticated': (r) => r.json().authenticated === true,
    'is correct user': (r) => r.json().user === username,
  });

  // Alternatively you can create the header yourself to authenticate
  // using HTTP Basic Auth
  const encodedCredentials = encoding.b64encode(credentials)
  const options = {
    headers: {
      Authorization: `Basic ${encodedCredentials}`,
    },
  }

  res = http.get(
    `https://quickpizza.grafana.com/api/basic-auth/${username}/${password}`,
    options
  )

  // Verify response (checking the echoed data from the QuickPizza
  // basic auth test API endpoint)
  check(res, {
    'status is 200': (r) => r.status === 200,
    'is authenticated': (r) => r.json().authenticated === true,
    'is correct user': (r) => r.json().user === username,
  });
}
```

**Explanation:** This is a sample code for  Basic Authentication.
