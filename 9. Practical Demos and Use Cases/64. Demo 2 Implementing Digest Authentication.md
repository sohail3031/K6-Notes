When use Basic Authentication, it will send data in the form of plane text which is not secure. It is possible to encrypt the data and send it for authentication proposes. To achieve this, we need to add "digest" auth in the header. See the code below:

**Code:**

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

export const options = {
	vus: 5,
	duration:"1m"
};

const username = "user";
const password = "passwd";

export default function() {
	let res = http.get(`http://${username}:${password}@httpbin.org/digest-auth/auth/${username}/${password}`, { auth: "digest" });
	
	check(res, {
		"status is 200": (r) => r.status === 200,
		"is authenticated": (r) => r.json().authenticated === true,
		"is correct user": (r) => r.json().user === username
	});
	
	sleep(1);
}
```
