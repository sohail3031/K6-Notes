In this lecture, we will understand the sample links available for testing in K6.

When starting with K6, having reliable sample links to test against is extremely valuable. These links provide controlled environments where we can practice K6 scripting, simulate various scenarios, and understand how K6 handles different types of requests and responses.

In future demos, we will use these links frequently.

The purpose of this lecture is to understand:
- which sample links are available
- what each link is useful for
- what kind of scenarios we can test using them

> **Note:** This is not a complete list of testing resources. It is a practical list of commonly used sample links for learning and demonstrations.

---

## 1. `https://test.k6.io/`

This is a sample web application designed specifically for testing K6 scripts.

It is a great starting point for beginners to understand basic HTTP requests and response handling in K6.

### What you can test
- Static content requests such as:
  - HTML pages
  - Images
  - CSS files
- Login form submission
- Response time analysis for different page elements

### Use cases
- Learning basic `GET` requests
- Testing form submissions
- Understanding session handling
- Measuring frontend resource loading performance

---

## 2. `https://test-api.k6.io/`

This is an API testing playground provided by K6.

It offers various endpoints for testing different API request scenarios.

### What you can test
- CRUD operations:
  - Create
  - Read
  - Update
  - Delete
- Authentication using API keys or tokens
- Error response handling

### Use cases
- API load testing
- Authentication testing
- Learning request/response validation
- Practicing robust error handling in scripts

---

## 3. `https://httpbin.test.k6.io/`

This is another K6-hosted testing utility for working with HTTP requests.

It provides endpoints for testing different HTTP methods, request headers, status codes, and more.

### What you can test
- HTTP methods:
  - `GET`
  - `POST`
  - `PUT`
  - `DELETE`
- Different HTTP status codes
- Custom headers
- Authentication mechanisms

### Use cases
- Request/response validation
- Header testing
- Status code handling
- Method-specific testing scenarios

---

## 4. `http://httpbin.org/`

`httpbin` is a simple HTTP request and response service that is widely used for API and HTTP testing.

### What you can test
- HTTP methods:
  - `GET`
  - `POST`
  - `PUT`
  - `DELETE`
  - `PATCH`
  - `OPTIONS`
- Basic authentication and digest authentication
- Status code testing
- Request inspection

### Use cases
- Understanding raw request and response structures
- Testing headers, query parameters, and request bodies
- Validating authentication flows

---

## 5. `https://jsonplaceholder.typicode.com/`

This is a free online REST API for testing and prototyping.

It is very useful for learning CRUD operations and working with JSON responses.

### Available resources
- Posts
- Comments
- Albums
- Photos
- Todos
- Users

### What you can test
- CRUD operations on different resources
- JSON response parsing
- Request chaining and validation

### Use cases
- API testing practice
- JSON parsing in K6
- Validating structured response data

---

## 6. `https://pokeapi.co/`

PokeAPI is a RESTful API that provides Pokémon-related information.

It is a fun and practical API for learning how to work with structured and nested API responses.

### What you can test
- Pokémon-related resources such as:
  - Pokémon
  - Abilities
  - Moves
  - Types
- Query parameter usage for filtering and searching
- Nested JSON objects and arrays

### Use cases
- Practicing JSON parsing
- Working with nested API responses
- Testing query parameter handling

---

## 7. `https://reqres.in/`

Reqres is a hosted REST API designed for testing and prototyping frontend and backend API interactions.

### What you can test
- User registration and login
- CRUD operations
- Pagination handling
- Error response simulation

### Use cases
- Authentication flow testing
- User management scenarios
- Pagination validation
- Handling negative API test cases

---

## 8. QuickPizza Repository

QuickPizza is a sample application from Grafana designed to demonstrate observability and performance testing features, including K6 foundations.

It contains several K6 scripts that are very useful for learning and demonstrations.

### What you can learn from QuickPizza
- Basic HTTP requests
- Response validation using checks
- Simulating multiple Virtual Users (VUs)
- Parameterizing tests using environment variables
- Handling authentication, cookies, and headers
- Understanding K6-specific examples built by Grafana

### Why it is useful
Since it is maintained by Grafana, it is especially helpful for learning K6 best practices and exploring K6 features through practical examples.

# Summary of Sample Links

| Resource | Purpose |
|---|---|
| `test.k6.io` | Basic website testing, static content, forms, response times |
