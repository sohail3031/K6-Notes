## Structure of a K6 Script

A typical K6 script consists of:

- Imports  
- `setup()` function (optional)  
- `default` function (main test logic)  
- `teardown()` function (optional)  

---

## Imports in K6

We use the `import` statement to include K6 modules.

Common imports include:

- `http` → for making HTTP requests  
- `check` → for validations/assertions  
- `sleep` → for simulating user think time  

Example:

```javascript
import http from "k6/http";
import { check, sleep } from "k6";
```

---

## Core Execution Flow

### 1. setup() Function

The `setup()` function runs once before the test starts.

It is used to initialize data or prepare the test environment.

Example use cases:

- Preparing test data
- Setting initial configurations
- Logging setup steps

---

### 2. default Function (Main Logic)

The `default` function is the main entry point of the test.

- It is executed by each Virtual User (VU)
- Each VU runs this function independently
- It simulates real user behavior

A Virtual User (VU) represents a simulated real-world user interacting with the system.

---

### 3. teardown() Function

The `teardown()` function runs once after the test completes.

It is used for cleanup activities such as:

- Releasing resources
- Logging final output
- Resetting test environment

---

## HTTP Requests in K6

K6 uses the `http` module to make requests.

Example:

```javascript
let res = http.get("https://test.k6.io");
```

---

## Using check() for Validation

The `check()` function is used for assertions.

It verifies whether the response meets expected conditions.

Example:

```javascript
check(res, {
    "status was 200": (r) => r.status === 200
});
```

- Takes HTTP response as input
- Uses a key-value object for assertions
- Helps validate test results

---

## Simulating User Behavior with sleep()

The `sleep()` function pauses execution for a specified time.

This simulates real user "think time".

Example:

```javascript
sleep(1);
```

---

## Complete Example Script

```javascript
import http from "k6/http";
import { check, sleep } from "k6";

// optional setup function
export function setup() {
    console.log("Setup: Initializing Data...");
}

// main test logic
export default function () {
    let res = http.get("https://test.k6.io");

    check(res, {
        "status was 200": (r) => r.status === 200
    });

    sleep(1);
}

// optional teardown function
export function teardown() {
    console.log("Teardown: Cleaning Up...");
}
```

---

## Execution Flow Summary

When you run a K6 script:

1. `setup()` executes once (if defined)
2. `default()` runs for each Virtual User
3. `teardown()` executes once after test completion

---

## Running the Script

Execute the script using:

```bash
k6 run script.js
```
