In this lecture, we will go through a sample K6 script that demonstrates the use of **Virtual Users (VUs)** and **test duration**.

This is one of the most basic and commonly used K6 test configurations.

The goal is to understand how to:
- configure a fixed number of Virtual Users
- run the test for a fixed duration
- send an HTTP request
- validate the response
- simulate user think time

---

## Objective of This Example

In this script:

- **10 Virtual Users** will run concurrently
- the test will execute for **1 minute**
- each Virtual User will repeatedly send a `GET` request
- the response will be validated using `check()`
- `sleep(1)` will simulate real user delay between actions

---

# K6 Script for Fixed Duration

```javascript id="k6-fixed-vus-duration-demo"
import http from "k6/http";
import { sleep, check } from "k6";

export const options = {
  vus: 10,          // number of virtual users
  duration: "1m"    // duration of the test
};

export default function () {
  let res = http.get("https://test.k6.io");

  check(res, {
    "status is 200": (r) => r.status === 200
  });

  sleep(1);
}
```

---

# Code Breakdown

## 1. Importing Required Modules

```javascript
import http from "k6/http";
import { sleep, check } from "k6";
```

These imports bring in the modules required for the script:

- `http` → used to send HTTP requests
- `check` → used to validate responses
- `sleep` → used to pause execution and simulate user think time

---

## 2. Defining Test Options

```javascript
export const options = {
  vus: 10,
  duration: "1m"
};
```

This `options` object contains the test configuration.

### `vus: 10`

- Specifies the number of **Virtual Users**
- 10 VUs means **10 concurrent users** will run the script at the same time

### `duration: "1m"`

- Specifies the total duration of the test
- The script will run continuously for **1 minute**

So, this configuration means:

> Run **10 Virtual Users** continuously for **1 minute**

---

## 3. The `default()` Function

```javascript
export default function () {
  let res = http.get("https://test.k6.io");

  check(res, {
    "status is 200": (r) => r.status === 200
  });

  sleep(1);
}
```

The `default()` function contains the actual test logic.

This function is executed by **each Virtual User** repeatedly during the test duration.

---

## 4. Sending an HTTP GET Request

```javascript
let res = http.get("https://test.k6.io");
```

This line sends an HTTP `GET` request to:

```text
https://test.k6.io
```

The response is stored in the variable `res`.

The response object contains information such as:

- status code
- response body
- headers
- timing information

---

## 5. Validating the Response Using `check()`

```javascript
check(res, {
  "status is 200": (r) => r.status === 200
});
```

The `check()` function is used to validate the response.

It takes:

1. the response object (`res`)
2. an object containing one or more validation checks

### In this case:

- the script checks whether the response status code is `200`
- if the condition is true, the check passes
- otherwise, the check fails

This is useful for verifying that the application is responding correctly during load testing.

---

## 6. Simulating Think Time with `sleep()`

```javascript
sleep(1);
```

The `sleep()` function pauses execution for **1 second**.

This simulates **real user think time** between actions and makes the load pattern more realistic.

Without `sleep()`, each Virtual User would send requests as fast as possible, which may not reflect real user behavior.

# Running the Script

To execute the script, open the terminal in the folder where the file is located and run:

```bash
k6 run script.js
```

If your file is named something like `vus-fixed-duration.js`, then run:

```bash
k6 run vus-fixed-duration.js
```

---

# What Happens During Execution?

When this test starts:

- K6 launches **10 Virtual Users**
- each Virtual User runs the `default()` function repeatedly
- the test continues for **1 minute**
- during each iteration:
    - a request is sent to `https://test.k6.io`
    - the response is checked
    - the Virtual User waits for 1 second

At the end of execution, K6 prints a summary containing:

- total iterations
- request duration metrics
- success/failure rates
- data sent/received
- VU statistics

---

# Key Takeaways

This example demonstrates how to run a K6 script with:

- a **fixed number of Virtual Users**    
- a **fixed test duration**
- an HTTP request using `http.get()`
- response validation using `check()`
- realistic user pacing using `sleep()`

---

# Summary

This is one of the simplest K6 performance testing setups:

- `vus` controls **how many users** run concurrently    
- `duration` controls **how long** the test runs
- `check()` validates responses
- `sleep()` adds realistic user behavior

This configuration is useful when you want to apply a **constant load** on the system for a specific period of time.
