**Executors:**
- Executors define scheduling and execution patterns for virtual users (VUs) in performance testing.
- Understanding executors is crucial for realistic and effective load testing.

**Choosing the Right Executor:**
- Consider your application expected production load patterns.
- Select the  executors that best replicates those patterns.

**Executors Types:**
1. **constant-vus:** Maintains a constant number of VUs for a specified duration.
	- **Use Case:** Apply a steady load on your system to observe behavior under consistent traffic.
	- **Example:** Load testing a web application to handle a specific number of concurrent users.
1. **ramping-vus:** Gradually increase or decrease the number of VUs over time.
	- **Use Case:** Simulate a gradual ramp-up and ramp-down of traffic.
	- **Example:** Testing an API for increasing and then decreasing request load.
2. **constant-arrival-rate:** Maintains a constant rate of iterations per time unit.
	- **Use Case:** Ensure a specific rate of requests per second.
	- **Example:** Stress testing a payment gateway to process a constant rate of transactions.
3. **ramping-arrival-rate:** Gradually increases or decreases the rate of iterations over time.
	- **Use Case:** Simulate a variable rate of traffic.
	- **Example:** Simulating user behavior during an e-commerce sale event.
4. **per-vu-iterations:** Runs a fixed number of iterations for each VU.
	- **Use Case:** Have each VU perform a specific number of actions.
	- **Example:** Testing a virtual user registration process with each VU completing the form multiple times.
5. **Shared Iterations:** Runs a fixed number of iterations shared among all VUs.
	- **Use Case:** Complete a fixed number of iterations regardless of VU distribution.
	- **Example:** Load testing a search functionality with fixed number of searches.
6. **externally-controlled:** Allows external control of active VUs in real-time via k6 REST API.
	- **Use Case:** Dynamically adjust the load during the test based on external metrics.
	- **Example:** Integrating with a monitoring tool to adjust server load in real-time.
