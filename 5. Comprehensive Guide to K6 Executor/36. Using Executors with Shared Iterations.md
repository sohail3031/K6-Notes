**Explanation:**
- Shared iterations among VUs
- Test end when all iterations are executed
- Use VUs and iterations options as a shortcut 
- **Note:** Iterations may not be evenly distributed
- To guarantee fixed iterations per VU, use per-VU iterations
- Suitable for quick performance tests during development
- Shift-left policy for early performance testing

**Code:**

```javascript
import http from "k6/http";
import { sleep } from "k6";

export let options = {
	scenarios: {
		shared_iterations_scenario: {
			executor: "shared-iterations", // iterations shared among all VUs
			vus: 10, // number of VUs to run concurrently
			iterations: 100, // total number of iterations to execute
			maxDuration: "1m" // maximum time a test can run
		}
	}
};

export default function() {
	http.get("https://test-api.k6.io/public/crocodiles/");
	
	sleep(1);
}
```
