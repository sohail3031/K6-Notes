**k6 Environment Setup**
1. **Prerequisites:**
	- Basic performance testing knowledge
	- Command-line familiarity
	- Node.js installed (Optional)
	- Code editor installed
	- Internet access
2. **Installing K6:**
	- **Homebrew:** brew install k6
	- **Chocolatey:** choco install k6
	- **Linux:** Download and install from K6 website
3. **Setting Up Your Project:**
	- Create project directory
4. **Writing Your First Test Script:**
	- Create script.js
5. **Running Your Test:**
	- **Command:** k6 run script.js
	- Check for errors

**Code:**
```javascript
import http from "k6/http";
import { sleep } from "k6";

export let options = {
	vus: 10,
	duration: 30s
}

export default function() {
	http.get("https://test.k6.io");
	
	sleep(1);
}
```

**Command to Run K6:**
```bash
k6 run script_name.js
```
