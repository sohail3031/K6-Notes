## **What is graceful stop?**

**Graceful stop** is the time k6 waits **after the scenario duration ends** to allow:

- ongoing requests to finish    
- iterations to complete
- no abrupt interruption

So instead of killing VUs immediately, k6:  
👉 waits a little extra time  
👉 lets active work complete safely

---

# **Key idea (simple)**

- `duration` → when scenario stops scheduling new iterations
- `gracefulStop` → time allowed to finish running iterations

---

# **Correct behavior flow**

1. Scenario runs for `duration`
2. k6 stops assigning new work
3. Existing iterations continue
4. k6 waits for `gracefulStop`
5. If still running → force stop

---

# **Correct Code (Fixed)**

⚠️ Your mistake:  
`gracefulstop` ❌ → should be `gracefulStop` (camelCase)

```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
	scenarios: {
		graceful_stop_scenario: {
			executor: "constant-vus",
			vus: 5,
			duration: "10s",
			gracefulStop: "5s"
		}
	}
};

export default function () {
	http.get("https://test.k6.io");
	sleep(1);
}
```

---

# **Why this is correct**

### ✔ `gracefulStop` works because:

- It is a **valid scenario-level property**
- Applies after `duration` ends
- Prevents abrupt termination of iterations

---

# **Why your version was incorrect**

### ❌ `gracefulstop`

- k6 is **case-sensitive**
- property must be exactly: `gracefulStop`
- wrong casing → property ignored completely

---

# **What happens without gracefulStop?**

If omitted:

- k6 may **forcefully stop VUs**
- active HTTP requests may get cut
- results may include incomplete metrics

---

# **Why graceful stop matters**

It improves:

- ✔ accuracy of response metrics
- ✔ reliability of test results
- ✔ realism of user behavior
- ✔ safe shutdown of scenarios

---

# **Real-world analogy**

Imagine:

- users are submitting a payment
- test ends suddenly

Without graceful stop:  
👉 payment request might be cut midway ❌

With graceful stop:  
👉 system waits for completion ✔

---

# **Quick exam takeaway**

- `duration` → stops new iterations
- `gracefulStop` → finishes running ones
- default → `30s` if not set
