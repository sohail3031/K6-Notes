In this lecture, we will learn how to create a **data source** in Grafana and use it to build a **dashboard**. Grafana provides a built-in **TestData** data source that generates synthetic data, which is useful for learning, experimentation, and dashboard design without connecting to a real data source.

## Creating a Test Data Source

Grafana includes a built-in **TestData** data source that can generate fake/sample data for testing and demonstration purposes.

To create it:

- Open the Grafana home page.    
- Go to **Connections** -> **Data sources**.
- Click **Add new data source**.
- Search for **TestData**.
- Select the **TestData** data source.
- Provide a meaningful name for the data source.
- Save the data source.

Once saved, the TestData source will be available in the list of configured data sources.

## Purpose of the TestData Data Source

The **TestData** data source is useful when you want to:

- Practice creating dashboards without connecting to a real system
- Experiment with different panel types and layouts
- Learn how queries and visualizations work
- Troubleshoot panel configuration
- Fine-tune dashboards before connecting them to actual production data sources

It is mainly intended for **learning, testing, and demonstrations**.

## Creating the First Dashboard

After creating the TestData data source, you can use it to create your first dashboard.

### Steps:

- Create a new dashboard.
- Click **Add visualization**.
- Select the **TestData** data source.
- Configure a query for the panel.

This creates the first panel in the dashboard.

## Using the Random Walk Scenario

One of the common sample scenarios provided by TestData is **Random Walk**.

The Random Walk scenario generates time-series data that changes over time. It is useful for simulating metrics such as CPU usage, response times, or other fluctuating values.

### Important Random Walk Options

#### 1. Series Count

**Series count** specifies how many data series should be generated.

- `1` = one line/series
- `3` = three different series plotted together

This is useful when you want to simulate multiple related metrics in the same panel.

#### 2. Alias

**Alias** allows you to assign a custom name to a generated series.  
If left blank, Grafana uses the default series name.

#### 3. Start Value

This defines the initial value from which the random walk begins.

- **Auto** = Grafana selects a starting value automatically
- Numeric value = the series starts from that specific value

Example: if the start value is set to `1000`, the generated data begins around 1000.

#### 4. Minimum and Maximum

These values define the lower and upper bounds for the generated data.

- **Minimum** = lowest value the series can drop to
- **Maximum** = highest value the series can rise to

If left empty, there is no limit.

#### 5. Spread

**Spread** controls how much the value can increase or decrease at each step.

- Small spread = smoother line with smaller changes
- Large spread = more volatile line with bigger fluctuations

For example:

- Spread = `1` → each point changes only slightly
- Spread = `100` → larger jumps in the data

#### 6. Noise

**Noise** adds extra randomness to the data.

- `0` = no additional noise
- Higher values = more unpredictable/random data

This is useful when you want the generated series to look less uniform.

#### 7. Drop Percentage

**Drop percentage** simulates missing data points.

- `0%` = no missing data
- Higher percentages = more data points are randomly omitted

This helps simulate real-world cases where telemetry or metrics data may be incomplete.

## Saving the Dashboard

Once the panel is configured:

- Save the dashboard
- Provide a **dashboard title**
- Optionally provide a **description**

Now you have created your first dashboard with one panel.

## Adding More Panels

You can add more panels to the same dashboard:

- Open the dashboard
- Click **Add** -> **Visualization**
- Select the same TestData data source (or another one)
- Configure a new query
- Choose a visualization type

Grafana supports many visualization types such as:

- Time series
- Bar chart
- Histogram
- Pie chart
- Table
- Stat panel
- Gauge
- Logs view

You can also customize chart options such as line width, graph style, colors, legends, and more.

## Organizing the Dashboard

Once multiple panels are added, you can:

- Rearrange panels
- Resize panels
- Edit visualization settings
- Save the updated dashboard

This allows you to create dashboards that are organized and easy to read.

## Summary

In this lecture, we learned how to:

- Create a **TestData** data source in Grafana
- Use the TestData source to build a **dashboard**
- Add a **panel** and configure a **Random Walk** query
- Understand important query options such as **series count, alias, start value, spread, noise, and drop percentage**
- Save the dashboard and add additional panels

The TestData data source is very useful for learning Grafana because it lets you practice building dashboards and panels without needing a real backend data source.
