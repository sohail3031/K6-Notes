In this lecture, we will learn how to access the **Grafana Cloud** portal and understand its basic features. We will also look at the difference between using **Grafana Cloud** and a **standalone/self-hosted Grafana installation**.

Grafana Cloud provides a managed environment where you can start using Grafana without worrying about server setup, upgrades, maintenance, or scaling. It also gives access to the **LGTM stack** components such as **Grafana**, **Loki**, **Tempo**, and related observability services.

## Accessing Grafana Cloud

To access Grafana Cloud:

- Open the official [Grafana website](https://grafana.com/?utm_source=chatgpt.com) in your browser.
- If you do not already have an account, sign up using your email address.
- Verify your email and complete the registration process.
- Log in to your Grafana Cloud account.

After logging in, you will be able to see the **Grafana Cloud portal/dashboard**, where you can access your stack, usage information, billing/subscription details, security settings, authentication tokens, and other account options.

## Launching Grafana from Grafana Cloud

From the Grafana Cloud portal, you can launch your Grafana instance and access the different observability components available in your cloud stack.

Typical components available in a Grafana Cloud stack include:

- [Grafana](https://grafana.com/products/cloud/?utm_source=chatgpt.com) — dashboards and visualization
- [Loki](https://grafana.com/oss/loki/?utm_source=chatgpt.com) — log aggregation
- [Tempo](https://grafana.com/oss/tempo/?utm_source=chatgpt.com) — distributed tracing
- Alerts / monitoring-related services
- OpenTelemetry integrations

These components together form the **LGTM stack** used for observability and monitoring.

## Advantages of Grafana Cloud

Grafana Cloud offers several advantages compared to a standalone installation:

- **Easy setup** – no need to manually install and configure servers.
- **Automatic updates and maintenance** – Grafana Cloud handles updates, patches, and platform maintenance.
- **Scalability** – it can handle larger workloads and users without you managing infrastructure.
- **Integrated observability stack** – easy access to Grafana, Loki, Tempo, and related services in one place.
- **Support for multiple data sources** – you can connect different monitoring and observability tools.
- **Free tier availability** – useful for learning and small-scale usage.

## Grafana Cloud Plans

Grafana Cloud provides multiple plans such as:

- **Free**
- **Pro**
- **Enterprise**

### Free Plan

The **Free plan** is suitable for learning, experimentation, and small projects. It usually includes enough features to explore Grafana Cloud and understand most of its capabilities.

### Pro and Enterprise Plans

The **Pro** and **Enterprise** plans are designed for teams and production workloads that need higher limits, more retention, advanced support, and enterprise-grade capabilities.

For learning purposes, the **Free plan is generally sufficient** to explore Grafana Cloud features.

## Managing Subscription and Usage

Within Grafana Cloud, you can also:

- Check current usage
- Review billing/subscription information
- Upgrade your subscription plan if needed
- Access security and authentication settings
- Manage tokens and other account-level configurations

## Summary

Grafana Cloud is a managed platform that makes it easy to start using Grafana and related observability tools without worrying about infrastructure management. It provides quick access to the LGTM stack, automatic maintenance, scalability, and a free plan that is sufficient for learning most Grafana features.

For this course or learning path, using the **Free Grafana Cloud account** is usually the best starting point.
