# 🧱 K6 Cloud Script Builder (Test Builder)

## 🎯 What is Test Builder?

The **K6 Test Builder** in Grafana Cloud is a **no-code / low-code interface** that lets you:

- Create performance tests visually    
- Configure load scenarios without writing scripts
- Automatically generate K6 test scripts
- Run and analyze tests directly in cloud

👉 Think: _“K6 without manual coding”_

---

# ⚙️ Key Idea

Instead of writing JavaScript:

```js
export default function () {
  http.get("https://example.com");
}
```

You simply:

- select URL    
- choose VUs
- define duration
- choose executor

👉 Grafana generates the script for you

---

# 🚀 How to Use Test Builder (Step-by-Step)

## 1. Go to Projects

Navigate:

```text
Testing & Synthetics →
Performance →
Projects
```

![[55. Using the K6 Cloud Script Builder 1.png]]

- Use existing project OR    
- Click **Create New Project**

---

## 2. Create Project (Optional Settings)

You can define limits like:

- Max VUs (e.g., 100)    
- Max VUs per test (e.g., 20)
- Max duration (e.g., 1 hour)

![[55. Using the K6 Cloud Script Builder 2.png]]

👉 These apply to all tests in the project

---

## 3. Create New Test

Click:

- **Create New Test**    
- Choose **Option 3 → Test Builder**

![[55. Using the K6 Cloud Script Builder 3.png]]

---

## 4. Start Builder Mode

Click:

👉 **Start Building**

![[55. Using the K6 Cloud Script Builder 4.png]]

Now you can:

- visually configure test    
- or switch to scripting mode anytime

---

# 🧪 Test Configuration

## 5. Define Scenario

Example setup:

- Scenario name: `test1`    
- Method: `GET`
- URL: `https://test.k6.io`

![[55. Using the K6 Cloud Script Builder 6.png]]

---

## 🔁 Toggle Between UI and Script View (IMPORTANT STEP)

The Test Builder allows you to switch between:

- Visual Builder (no-code UI)
- Auto-generated Script View

👉 This is where Grafana shows the generated K6 script in real time

![[55. Using the K6 Cloud Script Builder 5.png]]

You can:

- inspect generated code
- understand how UI maps to script
- modify logic if needed

---

## 6. Add Validation (Checks)

You can validate:

- HTTP status code    
- JSON path
- text match
- regex validation

Example:

- status = 200 ✔

---

## 7. Choose Executor Type

Same executors you learned earlier:

- constant-vus    
- ramping-vus
- shared iterations
- arrival rate

![[55. Using the K6 Cloud Script Builder 7.png]]

---

## 8. Set Load Configuration

Example:

- VUs: 5    
- Duration: 30s
- Ramp-down: 30s

👉 This creates full load profile visually

---

## 9. Auto-Generated Script

Grafana automatically generates:

```js
export default function () {
  http.get("https://test.k6.io");
}
```

Plus:

- scenarios    
- executors
- thresholds

# 🔄 Builder vs Script Mode

| Feature             | Builder | Script |
| ------------------- | ------- | ------ |
| Coding required     | ❌ No    | ✅ Yes  |
| Easy for beginners  | ✅ Yes   | ❌ No   |
| Flexibility         | Medium  | High   |
| Automation friendly | Low     | High   |

---

# 💡 Why Test Builder is Useful

- Fast test creation    
- No JavaScript needed
- Good for QA / non-dev users
- Helps learning K6 structure visually
- Converts UI → script automatically    

---

# 🧠 One-Line Interview Answer

> The K6 Test Builder in Grafana Cloud is a visual tool that allows users to create and run performance tests without writing code, automatically generating K6 scripts based on configured scenarios and load parameters.

---

# ⚠️ Important Note

Even though builder is easy:

- real-world teams still prefer **script-based K6**    
- builder is mainly for:
    - quick tests
    - demos
    - learning
