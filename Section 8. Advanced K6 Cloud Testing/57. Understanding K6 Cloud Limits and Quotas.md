Welcome to today's lecture on **limits and quotas in Grafana Cloud projects**.

This is an important concept because it ensures:

- Controlled resource usage    
- Avoids unexpected test failures
- Prevents exceeding billing limits

---

## ⚙️ What are Limits and Quotas?

Grafana Cloud applies **limits and quotas** on K6 usage to:

- Ensure fair usage across users    
- Prevent resource abuse
- Control infrastructure cost
- Maintain system stability

These limits depend on your **subscription plan**.

---

## 📊 Project-Level Limits

When creating a project, you can define:

- Maximum virtual users per month    
- Maximum virtual users per test
- Maximum test duration

### Why this matters:

- Prevents uncontrolled load testing
- Helps manage billing
- Ensures predictable usage

---

## 💡 How Limits Work

If limits are set:

- Tests are restricted within defined boundaries    
- Billing is controlled based on usage

If limits are NOT set:

- Usage depends entirely on subscription plan
- You may get charged based on consumption

---

## 💰 Billing & Usage

Grafana Cloud provides a **billing dashboard** where you can monitor:

- Virtual user hours    
- Metrics usage
- Logs and traces usage
- Data retention period

### Free vs Paid Plan

| Feature | Free Tier         | Paid Tier     |
| ------- | ----------------- | ------------- |
| Metrics | Limited           | Scalable      |
| Logs    | Limited retention | Extended      |
| VUs     | Restricted        | High capacity |
| Billing | None              | Pay-as-you-go |

---

## 📉 What Happens When You Exceed Limits?

If quotas are exceeded:

- Tests may be **stopped automatically**    
- New tests may be **blocked**
- API requests may be **restricted**
- Execution may be **throttled**

---

## 📡 Monitoring Usage

Grafana Cloud provides tools to track usage:

- UI dashboard    
- API-based monitoring
- Project-level usage tracking

You can view:

- Monthly usage
- Remaining quota
- Active test consumption

---

## ⚙️ Managing Limits in Projects

You can modify limits via:

👉 **Projects → Managed Limits & Quotas**

Here you can:

- Increase or decrease VU limits
- Adjust test duration limits
- Control project-level usage

---

## 🧠 Best Practices to Avoid Limit Issues

### ✔ 1. Plan Your Tests

- Avoid running heavy tests frequently    
- Schedule tests during low usage periods

### ✔ 2. Optimize Test Design

- Reduce unnecessary virtual users
- Use efficient scenarios

### ✔ 3. Monitor Regularly

- Track usage in Grafana dashboard
- Set alerts if possible

### ✔ 4. Upgrade When Needed

- Move to higher plan if workload increases
- Avoid hitting soft limits repeatedly

---

## ⚠️ Important Note

Even if you are on a free plan:

- You can still use K6 Cloud    
- But usage is strictly limited
- Heavy testing should be done carefully
