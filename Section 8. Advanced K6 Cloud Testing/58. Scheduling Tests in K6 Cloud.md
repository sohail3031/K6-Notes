# ⏰ Scheduling Tests in K6 Cloud

## 🎯 Why Schedule Tests?

Scheduling in **Grafana Cloud K6** allows you to automatically run performance tests at predefined times without manual execution.

### 🔹 Why it is useful?

- Run tests during off-peak hours 🌙    
- Automate recurring performance checks 🔁
- Reduce manual intervention
- Enable continuous performance monitoring

---

## ⚙️ How to Schedule a Test

Instead of running tests manually again and again, you can schedule them.

---

## 📍 Step 1: Navigate to Scheduling

Go to:

```text
Testing & Synthetics →
Performance →
Projects →
Select a Project →
Select a Test →
Set up a schedule
```

![[58. Scheduling Tests in K6 Cloud 1.png]]

---

## 📍 Step 2: Configure Schedule

After selecting schedule option, you will see configuration settings.

You can define:

- Start time ⏱    
- Frequency (hourly / daily / weekly / monthly)
- Number of repetitions 🔁
- End condition (date or number of runs)

![[58. Scheduling Tests in K6 Cloud 2.png]]

---

## 📍 Step 3: View Scheduled Test

Once configured, the schedule gets saved and listed in the UI.

You can:

- View active schedules    
- Edit schedules
- Disable schedules

![[58. Scheduling Tests in K6 Cloud 3.png]]

---

## 📍 Step 4: Edit or Delete Schedule

If needed, you can:

- Modify schedule settings    
- Delete schedule completely

![[58. Scheduling Tests in K6 Cloud 4.png]]

---

## ⚠️ Important Note (Time Zone Behavior)

- UI shows **local time zone**    
- Grafana stores schedules in **UTC**
- No daylight saving adjustment
- You may need to adjust schedules manually twice a year

---

## 🔄 Schedule Management Options

You can configure:

- Frequency:    
    - Hourly
    - Daily
    - Weekly
    - Monthly
- Execution limits:
    - Run X times
    - Stop after a specific date

---

## 💡 Key Benefits

- Fully automated testing    
- Reliable periodic monitoring
- No manual triggering required
- Better production readiness validation

---

## 🧠 One-Line Interview Answer

> Scheduling in K6 Cloud allows automated execution of performance tests at predefined intervals or times, helping teams continuously monitor system performance without manual intervention.
