## 🚀 Getting Started with Script Editor

To begin:

Navigate to **Grafana Cloud → Testing & Synthetics → Performance → Projects**

Select a project and click:

👉 **Create New Script**

You will see two options:

- Test Builder    
- Script Editor

👉 This lecture focuses on **Script Editor**

---

## 🧑‍💻 Opening the Script Editor

When you open it, you get a full coding environment:

- Import scripts    
- Copy/paste code
- Write from scratch
- Use example templates

![[56. Editing Scripts in K6 Cloud Script Editor.png]]

---

## ✨ Features of Script Editor

The K6 Cloud Script Editor is a **VS Code–like environment** with:

### ✔ Key Features

- Syntax highlighting    
- Code completion
- Error detection
- Inline validation

👉 This makes it easier to write and debug performance tests

---

## 📝 Writing a Script

You can:

- Start with a blank script    
- Use built-in examples
- Modify existing templates

Example structure:

```js
import http from "k6/http";

export default function () {
  http.get("https://test.k6.io");
}
```

---

## ▶️ Running the Script

Once your script is ready:

1. Save the script (give it a name)    
2. Configure test settings:
    - Virtual Users
    - Duration
    - Thresholds
3. Click **Run Test**

---

## ⚙️ Execution Flow

When you run the test:

1. Script validation happens    
2. Test is uploaded to cloud
3. Execution starts
4. Real-time metrics are displayed

You can monitor:

- Virtual users
- Response time
- Failure rate
- Throughput

---

## 📊 Cloud Test Monitoring

During execution:

- VUs gradually increase    
- Requests are executed in real time
- Metrics are streamed to dashboard

You can stop the test anytime if needed.
