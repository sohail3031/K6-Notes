## 🎯 What is a Baseline?

A **baseline test** in K6 Cloud is a **reference performance test run** used for comparison with future test executions.

👉 It represents the “normal” or “expected” performance of your system.

---

## 💡 Why Baselines are Important

Baselines help you:

- 📊 Compare future test results    
- ⚠️ Detect performance regressions early
- 📈 Track improvements over time
- 📉 Identify unexpected performance drops
- 🧪 Maintain consistency across deployments

---

## ⚙️ How to Set a Baseline in K6 Cloud

Follow these steps:

```text
Testing & Synthetics →
Performance →
Projects →
Select a Project →
Select a Test →
Click on 3 dots (top-right) →
Set as Baseline
```

## 📌 What Happens After Setting Baseline?

- The selected test becomes the **reference point**    
- Future runs can be compared against it
- Baseline data is **protected from retention policies**
- It remains available for long-term analysis

---

## 🔄 How Baseline Comparison Works

Once set, you can:

- Compare response times ⏱    
- Compare error rates ❌
- Compare throughput 📊
- Identify regressions or improvements 📈

---

## 🚀 Key Benefits

- Early detection of performance issues    
- Clear performance benchmarking
- Better release validation
- Data-driven performance decisions
- Improved reporting and analysis
