## 🎯 What are Environment Variables?

In **K6 Cloud**, environment variables are **key–value pairs** used to store configuration data outside your script.

They are:

- 🔐 Encrypted at rest    
- 🔒 Securely injected at runtime
- ♻️ Reusable across multiple tests
- ⚙️ Managed centrally in Grafana Cloud

👉 Ideal for storing **URLs, tokens, credentials, API keys**

---

## 💡 Why Use Them?

- Avoid hardcoding sensitive data    
- Easier script reuse across environments (dev / staging / prod)
- Centralized configuration management
- Safer CI/CD integration

## 🔐 Using Environment Variables in K6 Script

K6 exposes cloud variables using:

```js
__ENV.VARIABLE_NAME
```

### Example:

```javascript
import http from "k6/http";
import { sleep } from "k6";

export default function() {
	const params = {
		headers: { Authorization: __ENV.AUTH_TOKEN }
	};
	
	http.get(__ENV.SERVICE_URL, params);
	sleep(1);
}
```

---

## 🚀 How It Works in K6 Cloud

When a test runs:

1. K6 checks **local environment variables**    
2. If not found → checks **cloud variables**
3. If passed via CLI → CLI value takes priority

👉 Order of precedence:

```text
CLI > Cloud > Undefined
```

---

## 🧪 Execution Flow Example

### Step 1: Run test without variables set

- Script runs    
- Variables are missing
- Request may fail or use null values

---

### Step 2: Define variables in Grafana Cloud

- Add `SERVICE_URL`    
- Add `AUTH_TOKEN`

---

### Step 3: Re-run test

- K6 injects variables automatically    
- Request succeeds
- API call executes correctly
