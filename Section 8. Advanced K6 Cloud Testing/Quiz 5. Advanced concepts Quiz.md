## **Question 1**

### ❓ What feature does the K6 Cloud Script Editor provide to assist with writing and debugging scripts?

1. Automatic Code Generation 
2. Syntax Highlighting, Code Completion, and Error Checking 
3. Built-in Browser 
4. Integrated Terminal

✔ **Correct Answer:**  
**Syntax Highlighting, Code Completion, and Error Checking**

### 💡 Why this is correct:

The K6 Cloud Script Editor is built like a VS Code–style IDE, so it supports:

- Syntax highlighting → improves readability
- Code completion → speeds up writing scripts
- Error checking → helps detect mistakes early

### ❌ Why others are wrong:

- **Automatic Code Generation** → not a core editor feature
- **Built-in Browser** → not part of script editor
- **Integrated Terminal** → not available in K6 cloud editor
