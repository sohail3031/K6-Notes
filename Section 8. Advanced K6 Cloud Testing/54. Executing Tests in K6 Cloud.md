# ☁️ K6 Cloud Execution (Grafana Cloud)

## 🎯 Goal of This Lecture

Run **K6 tests in Grafana Cloud instead of local machine**, so that:

- execution happens in cloud infrastructure    
- results are visualized automatically
- no local resource limitations

---

# ⚙️ Prerequisites

Before running cloud tests:

- ✅ Grafana Cloud account    
- ✅ K6 installed locally
- ✅ API token from Grafana Cloud

---

# 🔐 Step 1: Login to K6 Cloud

```bash
k6 login cloud -t <TOKEN>
```

### What this does:

- Authenticates your local K6 with Grafana Cloud    
- Stores session credentials
- Enables cloud execution

---

# 🚀 Step 2: Run Test in Cloud

```bash
k6 cloud <FILE_NAME.js>
```

### What happens:

- Script is uploaded to Grafana Cloud    
- Test runs on cloud infrastructure
- Metrics are streamed in real time

---

# 🧪 Example K6 Script

```javascript
import http from "k6/http";
import { sleep } from "k6";

export const options = {
  stages: [
    { duration: "1m", target: 20 },
    { duration: "1m", target: 20 },
    { duration: "1m", target: 0 },
  ],
  thresholds: {
    http_req_failed: ["rate<0.05"],
  },
};

export default function () {
  http.get("https://test-api.k6.io/public/crocodiles");
  sleep(1);
}
```

---

# 📊 What Happens in Grafana Cloud

Once executed:

## 1. Test Execution Flow

- Ramp-up: 0 → 20 VUs    
- Steady state: 20 VUs
- Ramp-down: 20 → 0 VUs

---

## 2. Real-time Dashboard Shows:

- 📈 Virtual Users (VUs)    
- ⏱ Response time (avg, p95)
- ❌ Failure rate
- ⚡ Requests per second
- 📊 Threshold pass/fail status

---

## 3. Visual Advantages

Compared to local K6:

| Feature       | Local K6   | K6 Cloud        |
| ------------- | ---------- | --------------- |
| Visualization | Basic CLI  | Rich dashboards |
| Scalability   | Limited    | High            |
| Storage       | Local only | Cloud stored    |
| Collaboration | No         | Yes             |

---

# 📂 Where to See Results in Grafana Cloud

Navigate:

```text
Testing & Synthetics →
Performance →
Projects →
Default Project →
Test Run
```

You will see:

- live test execution
- historical runs
- graphs and metrics

---

# ⚠️ Important Notes

- Free tier has limits on VUs and runs    
- Token must be kept secure
- Each `k6 cloud` run uploads script to cloud
- Data is automatically stored and visualized

---

# 🧠 Key Concept Summary

| Component     | Role                 |
| ------------- | -------------------- |
| K6 CLI        | Runs & uploads test  |
| Grafana Cloud | Executes test        |
| Dashboard     | Visualizes results   |
| Token         | Authenticates access |

---

# 💡 One-Line Interview Answer

> K6 Cloud allows us to run load tests directly in Grafana Cloud by uploading scripts via CLI, executing them on cloud infrastructure, and visualizing real-time performance metrics in dashboards.
