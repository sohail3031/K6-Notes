You have four options to run any k6 script. 
1. Locally in your machine
2. Locally in your machine and send output to Grafana Cloud
3. Write code locally and run the script in Grafana Cloud using cloud run command
4. Run script in Grafana Cloud

**Code:**

```javascript
import http from "k6/http";
import { check } from "k6";

export const options = {
	vus: 10,
	duration: "30s"
};

export default function() {
	const res = http.get("https://httpbin.test.k6.io/get");
	
	check(res, {
		"status is 200": (r) => r.status === 200
	});
}
```

**1. Command to run script locally:**

```bash
k6 run script.js
```

**2. Command to send output to Grafana Cloud:**

```bash
k6 run --out cloud script.js
```

Before running the above command, make sure you logged in with the below command.

```bash
k6 login cloud -t <TOKEN>
```

**3. Command to send the local script to cloud and run there:**

```bash
k6 cloud script.js
```

**4. Write and execute in Grafana Cloud**
