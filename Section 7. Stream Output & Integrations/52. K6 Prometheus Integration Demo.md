# 🚀 K6 + Prometheus Integration (Grafana Cloud Demo)

## 🎯 Goal of Integration

Send **real-time K6 performance metrics** to **Prometheus (Grafana Cloud)** so that you can:

- Monitor test execution live    
- Store metrics as time-series data
- Visualize results in Grafana dashboards
- Query using PromQL

---

## 🔗 Key Components

- **K6** → Generates load & metrics    
- **Prometheus (Grafana Cloud)** → Stores metrics (time-series DB)
- **Grafana** → Visualizes data using dashboards
- **PromQL** → Query language for analysis

---

## ⚙️ What You Configure in Grafana Cloud

From Grafana Cloud you get:

- 📍 Prometheus Remote Write URL    
- 👤 Username (instance ID)
- 🔑 API Token (password)

These are required for authentication.

---

## 🧪 K6 Test Script (Example)

```javascript
import http from "k6/http";
import { sleep, check } from "k6";
import { Counter } from "k6/metrics";

export let errorRate = new Counter("errors");

export let options = {
  vus: 5,
  iterations: 100,
  thresholds: {
    errors: ["rate<0.1"],
  },
};

export default function () {
  let res = http.get("https://test-api.k6.io");

  check(res, {
    "status is 200": (r) => r.status === 200,
  });

  if (res.status !== 200) {
    errorRate.add(1);
  }

  sleep(1);
}
```

## 🏃 Running K6 with Prometheus Output

```bash
K6_PROMETHEUS_RW_USERNAME=<USERNAME> \
K6_PROMETHEUS_RW_PASSWORD=<API KEY> \
K6_PROMETHEUS_RW_SERVER_URL=<URL> \
K6_PROMETHEUS_RW_TREND_STATS=count,sum,min,max,avg,med \
k6 run -o experimental-prometheus-rw <FILE_NAME.js>
```

---

## 📊 What Happens During Execution

1. K6 starts test (5 VUs, 100 iterations)    
2. HTTP requests are executed
3. Metrics are generated:
    - response time
    - request count
    - errors
4. Metrics are streamed → Prometheus (Grafana Cloud)
5. Data is stored as time-series
6. Grafana reads it using PromQL

---

## 📈 Example Metrics Sent

- `http_req_duration`    
- `http_reqs`
- `errors`
- `vus`
- custom counters (like `errors`)

---

## 📊 Grafana Usage

Once data is inside Prometheus:

You can:

- Build dashboards    
- Create alerts (e.g., error rate > threshold)
- Query using PromQL like:

```promql
rate(http_reqs[1m])
```

---

## ⚠️ Important Notes

- API token must be kept secure    
- URL must match Grafana Cloud Prometheus endpoint
- `experimental-prometheus-rw` is required for streaming
- Metrics are sent in real time (not only at end of test)
