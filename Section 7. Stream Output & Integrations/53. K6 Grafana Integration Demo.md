# 📊 K6 + Grafana Integration (Dashboard Visualization)

## 🎯 Goal of This Step

After sending K6 metrics to **Prometheus (Grafana Cloud)**, the next step is:

👉 **Visualize the data in Grafana dashboards**

Because:

- Prometheus = storage + query (PromQL)    
- Grafana = visualization + dashboards

---

## 🔄 End-to-End Flow

```text
K6 → Prometheus (Grafana Cloud) → Grafana Dashboard → Visualization
```

---

## 📦 What You Already Have

From previous lecture:

- K6 test is running    
- Metrics are stored in **Prometheus**
- Data includes:
    - response times
    - requests/sec
    - errors
    - VUs

---

## 📊 Why Grafana is Needed

PromQL alone gives:

- raw query results    
- table-based output

Grafana adds:

- 📈 graphs
- 📉 trends over time
- 📊 dashboards
- 🚨 alerts

---

## 📥 Using Pre-Built K6 Dashboard

Grafana provides ready-made dashboards for K6:

### 🔎 Search:

```text
"K6 Prometheus Dashboard"
```

These dashboards are designed specifically for:

- `http_req_duration`
- `http_reqs`
- `vus`
- error rates
- throughput

---

## 🧭 Steps to Import Dashboard in Grafana

### 1. Open Grafana Cloud

Login → Open Grafana instance

---

### 2. Go to Dashboards

- Click **“Dashboards”**    
- Select **“New” → “Import”**

---

### 3. Import Dashboard

You can import using:

#### Option A: Dashboard ID

- Paste Grafana dashboard ID    
- Click **Load**

#### Option B: JSON File

- Upload downloaded JSON dashboard file

---

### 4. Select Data Source

- Choose **Prometheus (Grafana Cloud)** data source    
- This links dashboard to your K6 metrics

---

### 5. Click Import

Dashboard is now ready 🎉

---

## 📈 What You Will See in Dashboard

After running K6 test and refreshing:

### Key Visuals:

- 📊 Virtual Users (VUs)    
- ⏱ Request Duration (p95, avg)
- 📉 Error rate
- ⚡ Requests per second
- 📦 Throughput trends

---

## 🔄 Real-Time Behavior

When you re-run K6:

- Prometheus receives live metrics    
- Grafana dashboard updates automatically
- Graphs show live changes in:
    - load increase
    - response time spikes
    - system degradation

---

## 🧠 Why This Is Powerful

With K6 + Prometheus + Grafana, you can:

### ✔ Performance Monitoring

Track system health in real time

### ✔ Bottleneck Detection

Find slow APIs instantly

### ✔ Load Behavior Analysis

See how system behaves under:

- ramp-up    
- constant load
- spike traffic

### ✔ Correlation with Logs

Combine with logs (Loki) for debugging

---

## ⚠ Common Issue

If dashboard shows no data:

- Refresh Grafana dashboard    
- Confirm Prometheus data source is correct
- Ensure K6 test is running with `-o experimental-prometheus-rw`
