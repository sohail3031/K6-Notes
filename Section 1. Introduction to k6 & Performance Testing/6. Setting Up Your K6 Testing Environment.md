## Installation of K6

K6 can be installed on different operating systems, including:

- Windows  
- Linux  
- macOS  
- Docker  

In this course, we will focus mainly on Windows, while also demonstrating Linux and Docker-based setups.

---

### Windows Installation

The easiest way to install K6 on Windows is by using the official installer.

1. Download the MSI installer:  
   `k6-latest-amd64.msi`

2. Run the installer and follow the setup steps.

3. K6 will be installed in the default location:
```

Program Files/k6

````

4. The installer automatically adds K6 to the system PATH.

To verify this:

- Open **Environment Variables**
- Go to **System Variables → Path**
- Ensure `k6` path is present

---

### Verify Installation

Open Command Prompt and run:

```bash
k6
````

If installed correctly, you will see K6 command options displayed.

## First K6 Test Script (Verification)

We will use a simple script to verify that K6 is working correctly.

### script.js

```javascript
import http from "k6/http";
import { sleep } from "k6";

export let options = {
    vus: 10,
    duration: "30s"
};

export default function () {
    http.get("https://test.k6.io");
    sleep(1);
}
```

---

## Running the Test

You can run the test using:

```bash
k6 run script.js
```

Make sure you are inside the folder where the script is located.

You can also run it from Visual Studio Code terminal or Command Prompt.

---

## Expected Output

When you run the script successfully:

- K6 will simulate virtual users
- The test will run for 30 seconds
- You will see performance metrics in the terminal
- Summary statistics will be displayed after execution
