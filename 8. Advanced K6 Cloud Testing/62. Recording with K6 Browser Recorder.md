It is possible to record the test using Grafana Cloud and use that recording to test other tests with the same data. Follow the below steps to record a test.
.
	- Create a test using the same way as shown in [[55. Using the K6 Cloud Script Builder]].
	- Create a test using **Test Building** option.
	- You will see option for **Import a HAR File** or **Record a Scenario**.
	- If recording option is not available, then you need to install **Grafana Plugin** for recording.
	- Har file is same as JSON file for recording of test run using recording option from Grafana.
	- Save the recording and open it to check the options it used to run the test.
