**Command:**

```bash
k6 login cloud -t <TOKEN>
```

```bash
k6 cloud <FILE_NAME.js>
```

**Explanation:**
	- The command is required to login to Grafana Cloud.
	- You can find the login token in **Testing & Synthetics** -> **Performance** -> **Settings**.
	- When the second command is ran, it will send data into Grafana Cloud and we can see the results in the dashboard.
	- To see the running project, navigate to **Testing & Synthetics** -> **Performance** -> **Projects** -> **Default Project** ->**Select the Project**.
