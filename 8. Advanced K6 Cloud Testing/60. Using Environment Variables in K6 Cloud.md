Instead of storing environment variables locally, its possible to store the environment variables in the Grafana Cloud as well. Follow the below steps to store environment variables in Grafana Cloud.
.
	- To store environment variables in Grafana Cloud, navigate to **Testing & Synthetics** -> **Performance** -> **Settings** -> **Environment Variables**.
	- ![[60-1.png]]
	- Click on **New Variable**.
	- ![[60-2.png]]
	- You must first login the Grafana Cloud using the below command:.
	
```bash
	 k6 login cloud -t <TOKEN> 
```
	
	- When the scritp ran locally, it will first chekc if the environment variabls are present locally and if  not, it will check in cloud.
	- If the environment variables are provided via commandline, k6 will use it instead of using from cloud.

```javascript
import http from "k6/http";
import { sleep } from "k6";

export default function() {
	const params = {
		headers: { Authorization: __ENV.AUTH_TOKEN }
	};
	
	http.get(__ENV.SERVICE_URL, params);
	
	sleep(1);
}
```
