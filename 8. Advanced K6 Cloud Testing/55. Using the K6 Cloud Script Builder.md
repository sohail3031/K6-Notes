Instead of writing scripts, its possible to generate scripts in Grafana Cloud. You just have to provide the details such as number of virtual users, duration to run the script, and more. And Grafana will generate a script for you. You can run the script in the Grafana Cloud as well. Follow the below steps to get started.
. 
	- In Grafana Cloud, navigate to **Testing & Synthetics** -> **Performance** -> **Projects**.
	- You can either use the existing project or create a new one.
	- To create a new project, click on **Create New Project** button.
	- Provide appropriate inputs for the fields asked. Note: This are project level options and will be available to all the test scripts within that project.
	- Next, click on **Create New Test** button to create a test.
	- Select the **option 3** to create a script.
	- Click on **Start Buildering** button. When this option is selected, you can avoid writing scripts.
	- Click on **Start Scripting** button to write your script.
	- Play around and get your self familiar with the application.
	- You have two options, either you can just fill the values in the fields or you can write the script.
	- If you want to work on the script, toggle on the **View** toggle button. And turn it off to get back to the UI.
	- Finally, click on **Create and Run** button to run the test. You can see your script running shortly.
