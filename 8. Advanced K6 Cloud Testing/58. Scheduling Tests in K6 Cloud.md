Instead of running test manually again and again, its possible to schedule the tests to run automatically. Follow the below steps to schedule the tests:
.
	- In Grafana Cloud, navigate to **Testing & Synthetics** -> **Performance** -> **Projects** -> **Select a Project** -> **Select a Test** -> **Set up a schedule**.
	- ![[58-1.png]]
	- Once the option is selected, it will show some options.
	- ![[58-2.png]]
	- Once Selected, you can see the schedule.
	- ![[58-3.png]]
	- If you want to remove the schedule, click on **Edit Schedule** -> **Delete Schedule**.
	- ![[58-4.png]]
