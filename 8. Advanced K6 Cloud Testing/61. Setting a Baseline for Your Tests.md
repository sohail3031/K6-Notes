In Grafana Cloud, it is possible to select any one test and set it as a baseline test for your future tests for comparison purpose. Follow the below steps to set a test as a base line.
.
	- Navigate to **Testing & Synthetics** -> **Performance** -> **Projects** -> **Select Any Project** -> **Select Any Test** -> **Click on 3 Dots at Top Right Hand Side** -> **Set as Baseline**.
	- ![[61-1.png]]
	- ![[61-2.png]]
	- ![[61-3.png]]
	- You can use this test as a baseline to make a comparison with the future tests.
